# Getting started {#getting-started}

Install the engine, then classify one frame.

The install page builds `seams` 2.14.0 from a source checkout or with
pixi. The quickstart then classifies an eight-molecule cubic cell from
C and from Python, and reads the bundled TIP4P frame
`input/traj/exampleTraj.lammpstrj` (250 oxygens, LAMMPS type 2). The
videos page is the recording of that run.
