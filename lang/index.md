# Language APIs {#language-apis}

seams-core documents the C API and the C++ front here. Every other
language binding is its own package with its own documentation.
Each one links `libseams` or `libseams_lang`.

| Language | Repository | Package |
| --- | --- | --- |
| Python | d-SEAMS/PydSEAMSlib | pydseamslib (import dseams) |
| R | d-SEAMS/dseams-r | dseams |
| Julia | d-SEAMS/Dseams.jl | Dseams |
| Rust | d-SEAMS/dseams-rs | dseams-sys, dseams |
| Fortran | d-SEAMS/dseams-fortran | fpm Git dependency dseams |
| Lua, Fennel | d-SEAMS/yodaStruct | Git source; require("dseams") |
