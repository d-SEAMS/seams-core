## Detailed Documentation {#detailed-documentation}

One network-former atom: coordination, same-species bonds, and the primitive rings that pass through it.

`rings` counts are through this atom, so a ring of size n contributes to n rows. An index row may lead with the atom itself; that entry is not a neighbour.
