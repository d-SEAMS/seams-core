# struct sinp::ChemfilesLoadOptions {#struct-sinp-chemfilesloadoptions}

Name-based filtering and species overrides for chemfiles input. Include lists are ORed within a category and ANDed between residue and atom categories. Exclusions take precedence. typeMap is consulted before chemfiles element inference.
