# struct nucleation::GrowBasin {#struct-nucleation-growbasin}

Grow basin of one label. The barrier is the cluster size at the foot of that label’s own final strict climb to its maximum. A series that never climbs has occupied false: it never enters the basin. The barrier is not a shared multiple of the molecule count.
