## Overview {#overview}

## Detailed Documentation {#detailed-documentation}

Waters within `halfWidth` of either front, their primitive-ring census, and the coordination defects (a water whose oxygen neighbour count is not 4).

`ringCensus[s]` is the number of primitive rings of size s that lie entirely in the layer. `coordination[c]` counts waters with c neighbours, and the last bin also holds every larger count.
