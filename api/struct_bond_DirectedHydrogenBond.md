# struct bond::DirectedHydrogenBond {#struct-bond-directedhydrogenbond}

One directed hydrogen bond. Indices are positions in the single cloud passed to directedHydrogenBonds. Angle is degrees, acceptor-first: the two vectors are the minimum image of acceptor minus donor and the minimum image of acceptor minus the hydrogen. A linear donor-hydrogen-acceptor geometry has angle 0.
