## Detailed Documentation {#detailed-documentation}

Neighbour convention for the Errington-Debenedetti tetrahedral order.

### Enum Values {#enum-values}

The four nearest selected partners, with no radial cutoff.

Every selected partner at or inside the supplied cutoff. For N neighbours the standard 3/8 factor is generalized to 9/(2 N (N-1)), which keeps the ideal-gas mean at zero.
