## Detailed Documentation {#detailed-documentation}

Chordless cycles of one length.

`atoms` holds [count()](#doxid-structseams-1-1-chordless-cycles-1a03ffa11ffd11a5a39645c7627541b9de) rows of `size` atom indices, in the order seams_rings_chordless writes them. `per_atom` is the number of cycles through each atom.

### Fields {#fields}

Cycle length.

[count()](#doxid-structseams-1-1-chordless-cycles-1a03ffa11ffd11a5a39645c7627541b9de) rows of `size` indices.

Cycles through each atom.
