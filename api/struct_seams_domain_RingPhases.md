# struct seams::domain::RingPhases {#struct-seams-domain-ringphases}

Phases of the last ringsOf on this rank. Rebuild is the neighbour rows of this rank’s share. Search is the path enumeration. Primitive is the shortest-path test. Reduce is the local index map.
