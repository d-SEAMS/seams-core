Cutoff CSR#

The list both boxes build is one CSR of cloud indices. offsets has length nop + 1. The partners of atom i are cols[offsets[i] .. offsets[i + 1]], sorted, with no self entry. A pair is kept when the squared minimum image is strictly below the cutoff squared. half keeps that pair only on the lower cloud index. A length-3 box is orthorhombic (Lx, Ly, Lz). A length of at least 6 is a LAMMPS dump: bound spans, then tilt factors xy, xz, yz. Both enter nneigh::orthoFullCsr. The length-3 path fills the 27 image shifts once and walks that stencil when every cell is at most the cutoff and the grid has at least two cells on each axis. A wider cell uses the fractional minimum image. The builders call omp_set_dynamic(0) and take the team from omp_get_max_threads. Set OMP_NUM_THREADS. There is no thread-count argument. A region that is already parallel does not fork again.

Explicit primitive rings and periodic winding#

primitive::ringNetworkSymmetrized(offsets, columns, maxDepth) accepts a caller CSR. It unions directed edges with their reverse, removes self and duplicate edges, and then calls the same Franzblau primitive-ring search as the cutoff graph. primitive::ringSizeHistogram counts the returned rows by size. Malformed offsets and out-of-range columns are errors.

The stable C entry is seams_rings_from_csr. The existing seams_rings_histogram_n and seams_rings_vertices queries read its handle. The language ABI used by Python is seams_graph_rings; its first call with null packed-row buffers queries their lengths.

When geometry accompanies the graph, ring::ringWindings sums the minimum-image bond steps around each cycle in its listed vertex order and expresses the total in cell vectors. The result is the oriented integer winding: a ring that crosses the cell once along \(+x\) is \(+1\) on axis 0, and the reverse traversal is \(-1\). seams_rings_winding and seams_frame_ring_winding report the signed component along a selected pore axis. A ring is contractible only when all three components are zero. Thus an axis winding of zero does not by itself imply contractibility.

Tetrahedral order and LSI#

topoparam::tetrahedralOrder accepts independent centre and partner index selections. A centre is removed from its own partner set. The NearestFour convention uses the four nearest selected partners without a radial cutoff. The WithinCutoff convention uses all \(N\) selected partners at or inside the cutoff and evaluates

\[q = 1 - \frac{9}{2N(N-1)} \sum_{j<k}\left(\cos\psi_{jk}+\frac{1}{3}\right)^2 .\]

For \(N=4\) this is the Errington–Debenedetti factor \(3/8\), and NearestFour always uses it. A perfect tetrahedron gives \(q=1\). For uncorrelated directions each term averages \(4/9\), so an ideal gas averages \(q=0\) for every \(N\). Both conventions return quiet NaN when fewer than four neighbours are available; they never substitute zero.

topoparam::localStructureIndex is the Shiratani–Sasai index. It sorts selected-partner distances so that \(r_1<\dots<r_N\le r_c<r_{N+1}\), takes the \(N\) gaps \(\Delta_i=r_{i+1}-r_i\) for \(i=1,\dots,N\), and returns their population variance

\[I = \frac{1}{N}\sum_{i=1}^{N}\left(\Delta_i-\bar\Delta\right)^2 .\]

The last gap reaches the first partner beyond the cutoff. A centre with no partner inside the cutoff, or none beyond it, returns quiet NaN.

The stable C entries are seams_tetrahedral_order and seams_lsi. seams_frame_tetrahedral and seams_frame_lsi are the language ABI consumed by Python. A null selection with length zero means every frame atom; output order follows centre-selection order.

The face-edge window is the same string on the fronts that take it. The default is 2.65,3.15 in the coordinate units of the file. none (also off or false) leaves the cage bound to the face census. The CLI flag is --cage-edge. dseams.userframe.Frame.cages_by_signature("512", edge="none") passes it to seams_frame_signature_edge. A null C edge string keeps the default. pydseams.Frame.cages_by_signature and Lua dseams.cages_by_signature call findBySignature and do not read that window. Choose the window as the heavy-atom contact range of the model, and widen it for a compressed cell or a guest that stretches a cage. A nanometer file uses 0.265,0.315.

Fast q4 and q6#

Degrees 4 and 6 on an orthorhombic or restricted-triclinic cutoff shell use the solid-harmonic kernel inside chill::steinhardtQlCutoff. seams_q4q6 in include/seams.h is the installed pair on libseams. It writes local q4 and q6. seams_frame_q4_q6 in bindings/cxx/seams_lang.h returns both local values and, when the pointers are non-null, the Lechner-Dellago averages. seams_q4_q6 in src/include/internal/seams_c_api.h is the flat entry inside the library, not the installed seams_q4q6. Its box is ox, oy, oz, lx, ly, lz, the six numbers seams_chill_plus already takes. seams_q4_q6_lammps takes the nine-number LAMMPS cell. Both return 0 on success. q4 and q6 are required. A null q4bar or q6bar skips that average.

The Python, R and Julia q4_q6 wrappers in their binding repositories call seams_frame_q4_q6. seams steinhardt prints the means of the degrees named by --l (default \(q_4\) and \(q_6\)) and of each Lechner-Dellago average. The \(q_4\) and \(q_6\) means are this kernel. dseams.Frame.q4q6 returns the two local arrays from seams_q4q6.

Fused q4, q6 and CHILL+#

seams_frame_q4_q6_chill in bindings/cxx/seams_lang.h builds one cutoff list and, on that pass, the local Steinhardt \(q_4\) and \(q_6\), the Lechner-Dellago averages \(\bar q_4\) and \(\bar q_6\), and the published CHILL+ labels. The averages are the same neighbour mean of \(q_{lm}\) as steinhardtQlCutoff with averaging on. q4bar and q6bar may be null. Labels use the published closed edges, not ovito-chill+.

q4_q6_chill in PydSEAMSlib examples/ctypes/chill_plus.py calls that entry and returns q4, q6, q4bar, q6bar, labels and counts. SEAMS_LANG_LIB selects libseams_lang. Nucleation analysis reads q6bar.
