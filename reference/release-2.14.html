2.14.3 release notes#

These notes describe the user-visible changes since d-SEAMS 2.13.0. The upgrade from 2.13 is the upgrade guide.

2.14.3#

Added#

  • The with_openmp Meson option, a feature that defaults to auto, builds every loop single-threaded without OpenMP when disabled, and stops the configure step when enabled and an OpenMP parallel region does not link.

  • Fractional density profiles follow a triclinic cell axis or an arbitrary direction, with slab volumes taken from the cell. Pore profiles add a cell-edge axis and centre, cylindrical radial and azimuthal shells, and axial slabs, as number and mass density. A radial shell is the Voronoi cell of the perpendicular lattice clipped by the outer radius, times the pore-edge length. A crossing of that circle with a polygon edge is kept on the edge, including a crossing that lands on a vertex. Azimuthal sectors split a wedge, including a wedge of half a turn. Azimuth zero points along the perpendicular projection of the next cell edge, (axis + 1) mod 3. The radial coordinate is the distance to the nearest periodic image of the axis. Axis -1 selects the longest cell edge, and any other negative axis is rejected. r_max of zero covers the perpendicular face, and a negative r_max is rejected.

    Host-guest queries report the nearest framework site and contact counts by framework type. The distance is the triclinic minimum image. The shared helper is triclinicMinImage, also used by site distances, water selection, and the periodic distance functions, with the same refinement applied to batched, cached-frame, and 2D RDF (rdf2::sampleRDF_AA / seams_frame_rdf2d) distances outside the Smith ball. Outside the Smith ball it refines both the fractional wrap and, when linked, minimage’s candidate. The cell is reduced by Lagrange and Selling steps, and each reduced vector is re-evaluated from its integer coordinates in the cell with an error-free dot product. A descent then runs over the shortest member of each coset of L / 2L, which contains every Voronoi-relevant vector, so the result is the minimum image on every LAMMPS-legal cell. That includes FCC primitive, tiny tilts, tilts at xy = lx/2 and at the corner |xy| = |xz| = lx/2, |yz| = ly/2, and elongated cells. The descent starts from the fractional wrap when probes at 3/8 of each cell edge settle within three steps and at most one of the four probes at 3/8 of the cell diagonals does not, and from the Babai point otherwise. A binary64 result is kept only when little cancelled: the Babai step subtracted lattice vectors no longer than twice the wrap, a descent from the Babai point took at most two steps, a descent from the wrap took at most three steps, and the image is at least 1/16 of the wrap. Every other image is evaluated without cancellation error, from the recorded wrap steps with exact rounding errors or from its integer lattice coefficients with error-free products and compensated sums, and kept when it clears the Voronoi cell by more than its rounding. Near ties continue in extended precision until the norm stops falling, skipping a step that does not lower the norm for the next candidate. Non-finite inputs or intermediates, singular bases, and lattice coefficients at or above 2^52 report an error without poisoning the per-thread basis cache. On the cells in tests/test_pore.cpp, the returned length differs from the exact minimum by at most 4 ulps of the wrapped length, 4 * 2^-52 * |wrap|, and by at most 1e-14 relative. Those cells are 1200 with an edge aspect ratio up to 40, 3000 each at edge aspect 1e3, 1e5, and 1e8, and an aspect-1e8 cell whose wrap is about 4e7 times its image. A positive three-length box wraps each orthorhombic axis. A box with fewer than six values does not read tilt factors. A guest type equal to the framework type is an error. framework_type 0 keeps every other type.

    Mass density is the caller’s mass unit per cubic Angstrom. A mass in amu is amu per cubic Angstrom, and multiplying by 1.66054 converts that density to grams per cubic centimetre. The library does not apply the factor.

Changed#

  • The linkcell subproject pin moves from the v0.6.0 tag to d-SEAMS/linkcell main. That commit has the CSR single-pass path, the macOS OpenMP search and runtime-path fixes, the Meson sanitize option, which links every consumer with the ThreadSanitizer runtime, and the cargo_profile option, which builds the release Cargo profile in a subproject on every Meson version. The wrap and the offline pre-seeds do not apply an exception-typeinfo patch, because the pinned linkcell carries that fix. The conda OpenMP patch and the macOS runtime-path patch are removed.

  • The linkcell subproject pin moves from 0bc73576ceb4ea79909a3ad7a7931275b59a9fe4 to d-SEAMS/linkcell main at f5ea5d6f0cc490686daec5e8352fdee8bc9b2314. That commit defines linkcell::Error’s key function out of line in src/error.cpp and builds it as the shared library linkcell_eh (Meson eh_shared defaults to true; CMake LINKCELL_EH_STATIC is the fully static link). The wrap drops linkcell-exception-typeinfo.patch, and the Nix, Yggdrasil and conda pre-seeds drop the same manual patch, because the pin already contains the fix. Every target that includes the C++ headers links linkcell_eh, and libyodaLib keeps the one copy of the Rust archive. gen::mic::RangeError and pore::BoxError are dllexport from libyodaLib when SEAMS_EH_EXPORT is set and dllimport in every other translation unit, which is how the Windows build exports them; on ELF they stay one default-visibility typeinfo. The wrap and the Nix pre-seed still apply linkcell-omp-test.patch, which sets OMP_NUM_THREADS=2 for linkcell’s cargo tests, because Nix’s check hook would otherwise leave that two-worker check on one thread. Remove that patch when the pin sets the variable itself; f5ea5d6f0cc490686daec5e8352fdee8bc9b2314 does not.

  • The test suite keeps each listed input and its expected value on a shorter sample. Cage fuzz keeps the first 16 trials of seed 20261101 + frames*9973 + trial*10007, the eight half-box shifts, and the dense-graph rule. The ring oracle keeps the first 80 random graphs of seed 20261121 + threads at one and four threads, plus the hand-built cycles, components, and ice lattices. Carried liquid frames are two consecutive frames, and the 7-frame crystal graphs, chill-plus, and the 6-frame drift stay. SIMD sizes, Ql reference values, XYZ error sentences, and tracked-file git outcomes are each one table. docs_frame_tutorials is removed because docs_tutorial_interface, docs_tutorial_nucleation, and docs_tutorial_brine already run those mains. The science brine snippet is covered by docs_science_tutorials, which still requires hexagonal counts 733 and 741. Those frames are vendored and returned by an in-process urlretrieve, and a checksum miss fails the run. Molecule stills are copied from vendored bytes, and the pixel compare stays.

Fixed#

  • The capi_sanitize=thread build sets Linkcell’s sanitize=thread option, which rebuilds Linkcell, its Rayon pool and the Rust standard library with -Zsanitizer=thread (from the rust-src package in the pixi environment) and links the shared liblinkcell, so ThreadSanitizer sees the pool’s handoffs and joins. capi_suite no longer reports every chunk the pool runs as a data race when other processes keep half the cpus busy and seams::team::run hands its stages to Linkcell.

  • gen::mic::RangeError and pore::BoxError each have one default-visibility key function in libyodaLib, and linkcell::Error has its key function in linkcell’s shared liblinkcell_eh. The C API, built with hidden visibility, therefore reports a minimum-image or linked-cell range failure as SEAMS_ERR_RANGE and a pore box failure as SEAMS_ERR_BOX on libc++, which matches typeinfo by address. exception_typeinfo builds a hidden-visibility shared library and fails if its typeinfo addresses differ.

  • The exact minimum image checks that its starting image is a lattice translate of the pair’s displacement, and starts from the displacement’s own fractional wrap when it is not. With minimage 0.1.4 linked, its Euclidean image on a needle cell, such as edges 1e12, 1 and 0.4 with tilts of 0.3, is often off the lattice, and the tilted cutoff neighbour graph on that cell returned SEAMS_OK with pairs missing and extra. It now matches the build without minimage.

  • A linked-cell search that cannot represent the frame’s cell, because an edge needs more bins than linkcell allows or the cell is too large for its cell construction, is SEAMS_ERR_RANGE from the C API with linkcell’s message, instead of SEAMS_ERR_INTERNAL. The mutual neighbour graph and the other k-nearest paths on a needle cell, such as edges 2^30, 1 and 0.375, report it that way. A non-finite coordinate reported by linkcell is SEAMS_ERR_ARG.

  • libyodaLib no longer defines weak fallbacks for lc_set_threads, lc_num_threads, lc_set_places and lc_owned_mask. Linkcell 0.6.0, the oldest supported release, exports all four, and against a shared liblinkcell the dynamic linker bound libyodaLib’s calls to its own fallbacks, so the thread width never reached Linkcell.

  • The macOS CI SDK archive is downloaded under RUNNER_TEMP instead of the source tree, so the checkout does not gain an untracked MacOSX11.0.sdk.tar.xz before the source-tree tests.

  • With minimage linked, trajectory unwrapping, molecule centres, water orientation and dipole vectors, and seams_msd_push take a displacement past the Smith ball from the library’s bounded lattice search, as in the build without minimage, instead of minimage’s Euclidean image, which minimage 0.1.4 returns off the lattice on needle cells.

  • With minimage linked, the threaded cell-list neighbour rows, the nearest unlike atom behind seams_contact_pairs, the batched periodic distances and the pair loop of the RDF no longer take minimage’s batched wrap as the distance. minimage 0.1.4 returns wrong wrapped distances on needle cells, some of them inside the Smith ball where the result was kept as exact. The distances now come from the library’s own fractional wrap, and minimage’s Euclidean image only starts the exact search past the Smith ball.

  • With minimage linked, minimage’s Euclidean image is re-evaluated from its own lattice coefficients before the exact minimum-image search, the way the fractional wrap is. minimage 0.1.4 drops a tilt near 1e-14 of an edge, and loses tens of roundings on needle and elongated cells, and the lattice check accepted those images, so gen::refineEuclidean, the pore distances, the cached-frame distances and the 2D RDF returned an image off the lattice by that much. They now match the binary128 reference in tests/mic_oracle as the build without minimage does.

  • A minimum-image range error, from a tilted cell whose minimum image needs a lattice coefficient at or above 2^52, a numerically singular cell, or a non-finite intermediate, is SEAMS_ERR_RANGE from the C API with the minimum-image message in seams_last_error(), instead of SEAMS_ERR_INTERNAL. Host-guest queries and the other pore calls report it the same way.

  • The tilted-cell cutoff neighbour graph, CHILL, CHILL+, q4/q6 and the other paths through gen::refineEuclidean return SEAMS_ERR_RANGE on a cell outside the minimum-image range instead of keeping the fractional wrap. Keeping the wrap dropped about a fifth of the directed pairs, with SEAMS_OK, on a needle cell with edges 1e17, 1 and 0.4 and tilts of 0.3, at every thread count. With minimage linked, its candidate outside the Smith ball is now refined by the same exact minimum image as the other distance paths, so that cell no longer returns a wrong neighbour graph in that build either.

  • No OpenMP region in the library lets an exception escape any more. The primitive-ring search and its incremental updater, cage enumeration, affiliation and packing, the cage-topology, prism and fingerprint passes, the neighbour-list and cutoff-graph builders, the C API helpers, the 2D RDF, the shell matcher and the matrix product kernels now hand an exception, such as a failed allocation, to their caller after the region instead of terminating the process. The handler that keeps the first exception no longer takes a lock, and Eigen is built with EIGEN_DONT_PARALLELIZE, so it opens no OpenMP region of its own.

  • An exception inside a threaded neighbour, contact, CHILL, CHILL+, Steinhardt, bond-order, cage-matching, crystal-template or SOAP loop that measures minimum-image distances is returned to the caller once the loop ends, at one thread, at many threads and without OpenMP, instead of terminating the process. seams_contact_pairs on a cell outside the minimum-image range returns SEAMS_ERR_RANGE instead of aborting.

  • seams_rings_labels and seams_rings_labels_n return SEAMS_ERR_RANGE when the prism pass meets a minimum-image range error, instead of returning the size and cage labels without the prism codes.

2.14.2#

Added#

  • The stable C API (seams_rings_from_csr, seams_rings_winding) and the language ABI (seams_graph_rings, seams_frame_ring_winding) find primitive rings in a caller CSR graph. Directed edges are symmetrized, and with a periodic frame each ring reports its oriented winding along a cell axis and whether it is contractible.

  • The stable C API (seams_tetrahedral_order, seams_lsi) and the language ABI (seams_frame_tetrahedral, seams_frame_lsi) compute Errington-Debenedetti tetrahedral order and the Shiratani-Sasai Local Structure Index for independent centre and partner selections. The four-nearest and cutoff-shell conventions are explicit, and a centre whose shell is too small gets NaN.

  • LICENSE.note and AUTHORS give the licence and the authors of every part of the chemfiles build that d-SEAMS compiles and installs as libseams-chemfiles, down to the molfile plugin files under their own terms, including the DESRES DMS reader, the CPMD and Gaussian log readers, the mmtf-cpp authors and the lzma SHA-256 authors. The Data Formats page lists each molfile reader with its authors and copyright holder, and lists every plugin that is not built.

  • The chemfiles that d-SEAMS builds reads every VMD molfile format chemfiles 0.10.4 can compile and that returns atoms: 33 plugins and 37 formats instead of 3. Among them are PQR, XSF, Gaussian cube, AMBER7 restart and parm7, CHARMM coordinates, Maestro, VTF, DESRES trajectories and DMS, Gromacs g96, CPMD and Gaussian logs, DL_POLY, GAMESS, and VASP POSCAR, OUTCAR, XDATCAR and vasprun.xml. cmake/patches/chemfiles-0.10.4-molfiles.patch enables them in the Meson and CMake builds, and the DMS reader links the system SQLite3. Counting the frames of an AMBER7 restart no longer crashes, an AMBER7 restart with no atom count on its second line no longer hangs, and an empty file or a file in which a plugin finds no atoms is an error.

  • The workflow rules h2h_release_build, h2h_neighbours, h2h_rings, h2h_lanes, h2h_asv, h2h_inventory, h2h_summary and h2h_campaign run the head-to-head campaign as one chain on one shared --core (h2h_core, default 0) with at least 12 interleaved rounds (h2h_rounds and h2h_asv_rounds, default 12), and write a done marker under bbdir-h2h/<stamp>/. Running the h2h_campaign target on one core with h2h_stamp=<stamp> executes the chain; an interrupted stage resumes its run and skips the samples already recorded, and h2h_attempt=-2 adds a suffix to the run ids, raw logs and done markers of h2h_lanes, h2h_asv and h2h_inventory.

Analysis#

  • The C API and language ABI expose trajectory frames, neighbour lists, CHILL and CHILL+, primitive rings, cage signatures, Steinhardt order parameters, symmetry labels, and per-atom results.

  • The seams command reads LAMMPS, XYZ, chemfiles, and CON trajectories when the corresponding reader is enabled.

  • LAMMPS, GROMACS, OpenMM, PLUMED, and in-situ integrations can classify frames from running or completed simulations. The standalone PLUMED action (dseams-plumed v0.4.1) is indexed in PLUMED-NEST egg 26.018.

Performance and portability#

  • Cutoff and k-nearest neighbour searches, rings, order parameters, and cage analyses use shared-memory parallelism when OpenMP is available.

  • Restricted triclinic cells use the full periodic cell, and frame ranges preserve input order.

  • Optional backends include MPI, OpenMP target offload, Highway, chemfiles, readcon, IRA, sphericart, spglib, and nauty.

Interfaces#

The stable C interface is include/seams.h. C++ users can call the engine headers or include/seams.hpp. Python, Lua and Fennel, R, Julia, Rust, and Fortran bindings are documented on Use a language binding.
