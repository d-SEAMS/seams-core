# Lua and Fennel

The Lua and Fennel binding provides `require("dseams")`.

```bash
git clone https://github.com/d-SEAMS/yodaStruct.git
cd yodaStruct
luarocks make
```

Continue with the [Lua and Fennel binding documentation](https://lua.dseams.info/)
or watch it on the [videos page](../videos/index.html).
