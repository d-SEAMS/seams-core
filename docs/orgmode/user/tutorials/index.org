How-tos solve a goal you already have. Reference names flags and
headers. Explanation covers why CHILL+ and the cage census can disagree.

A paper tutorial has a fast run and a full run. The topics are
=interface=, =cages=, =rings=, =brine=, and =nucleation=. From the
repository root, after a pixi build, this writes the fast brine
picture and the lines that page quotes:

#+begin_src sh
pixi run python docs/tutorials/paper_science.py brine bbdir/seams bbdir/src out/brine
#+end_src

=out/brine/brine.png= is the picture. The full brine picture is the
same command with =brine-full= and =out/brine-full=, which writes
=out/brine-full/brine-full.png=. The other four topics use their own
name in those two places. =pixi run meson test -C bbdir docs_paper_brine= checks the
fast lines. =pixi run meson test -C bbdir --suite slow docs_paper_brine_full= checks the
full lines when the build was configured with =-Dpaper_full=true=.
Without that option the slow test exits 77. The other topics use the
same test names with their own topic. =snakemake -s
docs/tutorials/Snakefile brine= is the same full brine run. The
scripts are the Python files under =docs/tutorials=.
