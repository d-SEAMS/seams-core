#+TITLE: Quasi-one-dimensional ice
#+OPTIONS: toc:nil num:nil

A nanotube ice is a stack of prism blocks of one ring size.
~seams prisms~ counts perfect and imperfect prisms of size 3 to 6 on the mutual four-nearest graph.
The 2020 nanotube trajectory is figshare project 73545.
It is not in this repository, so this page does not give that file's prism count.

The in-tree confined frame is =input/traj/exampleTraj.lammpstrj=, 250 oxygens, LAMMPS type 2.

#+begin_src bash
seams prisms input/traj/exampleTraj.lammpstrj --type 2
#+end_src

#+begin_example
nop 250
size 3 perfect 0 imperfect 0
size 4 perfect 51 imperfect 0
size 5 perfect 0 imperfect 0
size 6 perfect 0 imperfect 0
perfect 51 imperfect 0
#+end_example

Fifty-one perfect four-membered prisms.
Ice Ih (~input/traj/ice1h.lammpstrj~, type 1) and frame 1 of the cubic cell (~input/traj/mW_cubic.lammpstrj~, type 1) print perfect 0 and imperfect 0 on every size.
Those crystals are hexagonal cages and double-diamond cages.
They are not a prism stack under this count.

The sheet census and the in-plane RDF are [[file:confined-water.org][Confined water]].
Bulk CHILL+ and cages on the same mixed dump are [[file:bulk-ice.org][the mixed TIP4P tutorial]].
The Lua examples for a nanotube dump are in yodaStruct.
shapeMatching uses [[https://raw.githubusercontent.com/d-SEAMS/yodaStruct/main/example_lua/iceNanotube/shapeMatching/config.yml][shapeMatching/config.yml]], [[https://raw.githubusercontent.com/d-SEAMS/yodaStruct/main/example_lua/iceNanotube/shapeMatching/iceType/vars.lua][shapeMatching/iceType/vars.lua]], and [[https://raw.githubusercontent.com/d-SEAMS/yodaStruct/main/example_lua/iceNanotube/shapeMatching/iceType/functions.lua][shapeMatching/iceType/functions.lua]].
strictCriterion uses [[https://raw.githubusercontent.com/d-SEAMS/yodaStruct/main/example_lua/iceNanotube/strictCriterion/config.yml][strictCriterion/config.yml]], [[https://raw.githubusercontent.com/d-SEAMS/yodaStruct/main/example_lua/iceNanotube/strictCriterion/iceType/vars.lua][strictCriterion/iceType/vars.lua]], and [[https://raw.githubusercontent.com/d-SEAMS/yodaStruct/main/example_lua/iceNanotube/strictCriterion/iceType/functions.lua][strictCriterion/iceType/functions.lua]].
In each example, config.yml ~variables:~ points to that example's iceType/vars.lua, and vars.lua ~functionScript~ points to its iceType/functions.lua; both paths start at the yodaStruct root, as in example_lua/iceNanotube/shapeMatching/iceType/vars.lua.
shapeMatching sets ~doShapeMatching=true~ and passes ~doShapeMatching~ to ~prismAnalysis~, while strictCriterion does not set it and passes false.
