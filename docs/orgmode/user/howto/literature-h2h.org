#+TITLE: Literature head-to-head
#+OPTIONS: toc:nil num:nil ^:nil

Two recorded comparisons of d-SEAMS 2.14.0. The eight-call session is
=scripts/h2h_literature.py=. The six-call sitting is
=scripts/h2h_rc3_sitting.py=, and its medians are the long table at
the end of this page. How that sitting sets a thread width is on
[[file:literature-reproduce.org][Reproduce the literature head-to-head]].

* Eight-call session

=scripts/h2h_literature.py= drops one warm-up and times eight calls in
one process. The median of that even sample is the mean of the two
central values. The quartiles are Hyndman-Fan type 7, from
=quantile_linear= in =scripts/h2h_protocol.py=. That module's own
=REPEATS= is 6. This script passes 8.
One thread is pinned with =taskset -c 0=. Eight threads are pinned
with =taskset -c 0-7=. The run records =Cpus_allowed_list= and does
not record the host name. The cutoff is 3.5 Å.

| code | version on the neighbour and ring rows | what is timed |
|------+----------------------------------------+---------------|
| mdapy | 2.0.0 | neighbours, \(q_4\), \(q_6\), diamond, metal CNA, rings |
| pyscal3 | 4.1.0 | neighbours, \(q_4\), \(q_6\), diamond, metal CNA |
| vesin | 0.6.2 | neighbour lists |
| SQQ | 0.5.8 | chordless shortest-path rings of size 4, 5, and 6 |
| IRA | reported by =ira_mod= | the 17-atom ice shell |
| ClavisCage | reported by =clavis_engine= | TRACE cages \(5^{12}\), \(5^{12}6^{2}\), \(5^{12}6^{4}\) |
| PLUMED | reported by the =plumed= package | \(q_4\), \(q_6\), coordination |

IRA is imported as =ira_mod= from the conda-forge package =ira=.
ClavisCage is imported as =clavis_engine=. PLUMED is loaded from
=PLUMED_KERNEL= when that variable is set. A kernel without the
symfunc module has no Q4, Q6, or COORDINATIONNUMBER.

Frames come from =scripts/gen_ideal_ice.py= and stay in memory unless
=--out= is passed. The oxygen bond is 2.75 Å. Ice Ic is the 8-atom
cubic cell. Ice Ih is the 8-atom orthorhombic cell made from two
hexagonal primitives, so the box has no tilt. The supercells are 128,
4096, and 110592 molecules. =input/traj/dump-l.lammpstrj= frame 1 is
512 atoms of type 1. The box edge is 11.808 Å, the number density is
0.311 Å^{-3}, and the median number of neighbours inside 3.5 Å is 56.
The script labels that frame =liquid-mw=.
=input/traj/exampleTraj.lammpstrj= contributes its 250 type-2
oxygens, phase =tip4p-o=. =input/traj/genice_sI.lammpstrj= is 46
oxygens and =input/traj/genice_sII.lammpstrj= is 136.

Agreement is per atom. Neighbour rows match when the neighbour sets
match. \(q_l\) matches when every atom is within \(10^{-6}\). Diamond
labels are compared after mapping d-SEAMS cubic (1) and hexagonal (0)
onto the mdapy and pyscal3 codes 1 and 4. Metal CNA is a different
label set and is reported against the diamond label, so an ice atom
that CNA calls other stays visible. Rings match when the size census
matches. For IRA, the 16 nearest neighbours inside 5 Å plus the atom
itself are matched to the ice Ih and ice Ic templates. The template
with the smaller distance is the label, and a distance above 0.2 Å
is left unclassified. =seams_symmetry_backend= is =kabsch= when
libira is not linked and =ira= when it is.

#+begin_src bash
python3 scripts/h2h_literature.py --lib bbdir/src/libyodaLib.so
#+end_src

=--out= defaults to =benchmarks/h2h-literature.csv= and =--log= to
=benchmarks/h2h-literature.txt=. With no =--lib=, the library is
=SEAMS_CORE_LIB= or =build/src/libyodaLib.so=. =--sizes= defaults to
128, 4096, and 110592. =--once CODE OP= times one operation on one
phase. =benchmarks/h2h_literature.py= calls the same script once per
method. It reads =H2H_PYTHON= and =SEAMS_CORE_LIB=.

=seams_diamond_cna= builds the cutoff list when the shell occupancy
\(n/V \times 4\pi r^3/3\) is at most 12, and the four nearest
neighbours when the occupancy is higher. The 512-atom frame is in
the second case: its median coordination inside 3.5 Å is 56. A
crystal shell stays on the cutoff list. The ideal cells are the
first case.

The cage rows orient hydrogens 0.96 Å along an out-degree-2
placement of the four nearest oxygen-oxygen bonds. On a crystal the
TRACE call uses a 0.35 nm cutoff and a 35 degree angle. On a crowded
shell the TRACE cutoff is 1.05 times the fourth-neighbour distance,
and it is not taken past 0.35 nm. d-SEAMS counts on the GenIce cells
in the test suite are 2 of \(5^{12}\) and 6 of \(5^{12}6^{2}\) on the
sI unit cell (46 oxygens), 16 and 48 on the \(2\times2\times2\)
replicate (368 oxygens), and 16 of \(5^{12}\) and 8 of \(5^{12}6^{4}\)
on sII (136 oxygens).

PLUMED Q4 and Q6 store the norm of the averaged spherical-harmonic
vector and omit \(\sqrt{4\pi/(2l+1)}\). The script multiplies by
that factor. The neighbour weight is a rational switch with
=R_0=3.5=, =D_MAX=3.5=, =NN=100=, and =MM=200=. This script does not
set =PLUMED_NUM_THREADS=. The timed PLUMED columns are in the sitting
below.

* Six-call sitting

=scripts/h2h_rc3_sitting.py= drops one warm-up and times six calls.
The median is the mean of the two central values. The interquartile
range is type 7. Ideal ice Ic uses oxygen bond 2.75 Å and cutoff
3.5 Å. The C API test locks ideal-ice \(q_4\) at 0.509175077 and
\(q_6\) at 0.628539361. Six-rings on that crystal are two per
molecule, 221184 at 110592 molecules.

The worker opens =bbdir-release/bindings/libseams_lang.so=. There is
no flag for another path. =--out= defaults to
=benchmarks/rc3-sitting.csv= and =--log= to
=benchmarks/rc3-sitting.txt=.

#+begin_src bash
python3 scripts/h2h_rc3_sitting.py
#+end_src

The run needs numpy, vesin, mdapy, freud, OVITO, ASE,
=rings_statistics_matter=, =clavis_engine=, =fastatomstruct=, and a
symfunc PLUMED. =PLUMED_LIB= names =libplumed.so=. Otherwise the
script takes it from the =plumed= executable on =PATH=. The vesin
probe runs first and stops the sitting if vesin is missing. A later
guest that fails is a =FAIL= line in the log and is left out of the
CSV.

One thread is =taskset -c 0=. Eight threads are =taskset -c 0-7=.
=OMP_NUM_THREADS= is that width and =OMP_DYNAMIC=FALSE=. The =cores=
column is =Cpus_allowed_list= read in the worker.
=widenAffinity= returns without changing the mask when the OpenMP
width is one thread. In this file the one-thread neighbour, CHILL+,
ring, and cage rows list =0-7=, and the one-thread \(q_4\), \(q_6\),
and PTM rows list =0=.

vesin is =NeighborList= with =full_list=True=, =algorithm="cell_list"=,
=n_threads= set to the row width, and the copy inside the timer. At
110592 molecules that median is 51.194 ms on one thread and 22.269 ms
on eight. =n_threads=0= would follow =OMP_NUM_THREADS=. This worker
passes the row width. A half list is a different pair count. The full
ice Ic list at 110592 molecules is 442368 directed pairs.

The PLUMED worker writes the version =2.10.2+symfunc=, converts
positions to nanometres, and cuts the rational switch at 0.35 nm.
It sets =OMP_NUM_THREADS= and does not set =PLUMED_NUM_THREADS=. In
PLUMED 2.10 =getNumThreads= reads =PLUMED_NUM_THREADS=, so both
thread columns of these PLUMED rows are the one-thread measurement.
The sitting that sets =PLUMED_NUM_THREADS= to the row width is on
[[file:../../explanation/performance-overview.org][the performance overview]].

=rings_statistics_matter.ring_statistics= is called with
=backend="rust"= and =num_threads= equal to the row width. The
worker writes version 0.3.0. The OVITO polyhedral template match
enables structure ids 6 and 7 and leaves the other templates off.
The d-SEAMS cell on that row is =seams_frame_symmetry= with tolerance
0.12. Both are labeled PTM in the table.
=OVITO_THREAD_COUNT= is set before =import ovito=.

King's shortest paths are =fastatomstruct= =RingMethod.King= through
size 6. A call that does not return inside 10 minutes is not written,
and the larger sizes for that width are skipped. Every size through
110592 molecules in this file did return.

On the GenIce cages, hydrogens are an ice-rule orientation of the
four nearest oxygens and are built before the timer. TRACE reads
that graph at 0.35 nm and 35 degrees. The driver builds the
\(2\times2\times2\) sI replicate because TRACE drops a ring that
crosses the periodic boundary, and that replicate is the frame on
which the two counts are compared. The d-SEAMS counts are the ones
in the test suite, listed above.

On every row that shares an operation, a molecule count, and a thread
count, the d-SEAMS median is the smaller one.
