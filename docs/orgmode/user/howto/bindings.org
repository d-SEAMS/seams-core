#+OPTIONS: toc:nil num:nil

This repository builds the engine, the C API =libseams= (=include/seams.h=),
the C ABI =libseams_lang= (=bindings/cxx/seams_lang.h=) and the ~seams~
command. :doc:`/stable/c` and :doc:`/stable/cpp` document those. Every other language is its own repository with its
own documentation, tests and releases:

| Language     | Repository                                               | Package                          | Links          |
|--------------+----------------------------------------------------------+----------------------------------+----------------|
| Python       | [[https://github.com/d-SEAMS/PydSEAMSlib][d-SEAMS/PydSEAMSlib]]       | ~pydseamslib~ (~import dseams~, ~import pydseams~) | =libseams=, =libseams_lang= |
| Lua, Fennel  | [[https://github.com/d-SEAMS/yodaStruct][d-SEAMS/yodaStruct]]         | LuaRocks ~dseams~                | =libseams=     |
| R            | [[https://github.com/d-SEAMS/dseams-r][d-SEAMS/dseams-r]]             | ~dseams~                         | =libseams_lang= |
| Julia        | [[https://github.com/d-SEAMS/Dseams.jl][d-SEAMS/Dseams.jl]]           | ~Dseams~, ~libseams_jll~         | =libseams=, =libseams_lang= |
| Rust         | [[https://github.com/d-SEAMS/dseams-rs][d-SEAMS/dseams-rs]]           | crates ~dseams-sys~, ~dseams~    | =libseams=     |
| Fortran      | [[https://github.com/d-SEAMS/dseams-fortran][d-SEAMS/dseams-fortran]] | fpm ~dseams~                     | =libseams=     |

A binding release carries the seams-core version it was built against, so
~pydseamslib==2.14.0~ calls the 2.14.0 engine. Each repository's README
gives its install command. [[file:../../development/repositories.org][The
repository map]] describes how the bindings pin and test against a
seams-core tag, the release order, and how to develop a binding against a
local seams-core checkout.

* Python

~pip install 'pydseamslib==2.14.0'~ installs ~import dseams~ (array
calls into the engine) and ~import pydseams~ (the Frame API on the
[[file:../../reference/python-frame.org][Python Frame]] page). The cubic ice
frame in this tree gives the counts the other languages and the CLI print:

#+begin_src python
>>> import numpy as np
>>> import dseams
>>> def ice():
...     xyz, edges, reading = [], [], False
...     handle = open("input/traj/ice1h.lammpstrj")
...     try:
...         while True:
...             line = handle.readline()
...             if line == "":
...                 break
...             if line.startswith("ITEM: BOX BOUNDS"):
...                 edges = []
...                 for _ in range(3):
...                     lo, hi = handle.readline().split()[:2]
...                     edges.append(float(hi) - float(lo))
...             elif line.startswith("ITEM: ATOMS"):
...                 reading = True
...             elif reading:
...                 parts = line.split()
...                 if len(parts) < 5:
...                     break
...                 xyz.append([float(v) for v in parts[2:5]])
...     finally:
...         handle.close()
...     return xyz, edges
>>> xyz, edges = ice()
>>> frame = dseams.Frame()
>>> frame.set_frame(np.asarray(xyz), np.asarray(edges))
>>> frame.count()
128
>>> int(frame.neighbours(3.5)[0][-1])
512
>>> int(frame.rings(3.5, 6)[2][6])
256
>>> round(float(frame.q4q6(3.5)[1].mean()), 6)
0.625855
>>> int(frame.chill_plus()[1][1])
128
>>> from ase import Atoms
>>> pos, box = dseams.from_ase(Atoms(symbols=["O"] * len(xyz), positions=xyz, cell=edges, pbc=True))
>>> frame.set_frame(pos, box)
>>> int(frame.chill_plus()[1][1])
128
#+end_src

* What the bindings share

The classifiers run in the engine; no binding reimplements one. The
cutoff-shell solid-harmonic kernel is ~seams_q4q6~ in ~seams.h~ and
~seams_frame_q4_q6~ in =libseams_lang=; the flat name ~seams_q4_q6~ lives in
~src/include/internal/seams_c_api.h~ and is not installed. The CLI command
is ~seams steinhardt~. ~--l~ names the degrees (default ~4,6~). ~--l 3,12~
asks for the hydrate pair.

#+begin_src bash
meson test -C bbdir seams_lang_fixtures seams_lang_frames

own suite against a seams-core tag.
