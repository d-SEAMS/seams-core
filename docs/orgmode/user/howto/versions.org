#+TITLE: Version pins
#+OPTIONS: toc:nil num:nil

~seams --version~ prints the version of that binary. The text is the
program name, a space, and the Meson project version. On this release
the line is:

#+begin_src text
seams 2.14.0
#+end_src

~seams_version_string()~ in ~seams.h~ returns that version.
~seams_lang_version()~ in ~libseams_lang~ returns it as well. This book
prints the same string as the Sphinx ~version~ and ~release~.

A source checkout writes the version in six places. On this tree every
one of them is 2.14.0, except the Doxygen field, which is ~v2.14.0~.

| file | field |
|------+-------|
| =meson.build= | =version:= of =project(= |
| =pixi.toml= | =[workspace] version= |
| =CITATION.cff= | =version= |
| =nix/package.nix= | =version= |
| =docs/source/Doxyfile_seams.cfg= | =PROJECT_NUMBER= (=v2.14.0=) |
| =docs/source/conf.py= | =version= and =release= |

The language packages built for this tag are versioned 2.14.0.
Match the package to the string from ~seams --version~.
