#+TITLE: Lean proofs
#+OPTIONS: toc:nil num:nil

=lean/= is a Lean 4 (Mathlib) model of three pieces of the engine.
=lean/DseamsProofs.lean= imports all three.
=lean/README.org= lists the completion theorems and the ~lake~ build.
The Coq and SymPy suite under =proofs/= is a different tree
(~pixi run -e formalanalysis verify-all~).

* Ring completion

=lean/DseamsProofs/Completion.lean= models
~ring::ringAdjacentCompletion~. Vertices are a finite type, rings are a
finite family of finite sets, and the labelled set is the seed. One
step labels every vertex that sits on a ring whose other vertices are
already labelled. The file proves:

- ~subset_step~ and ~step_mono~ :: ~step~ is extensive and monotone.
- ~iter_stable~ and ~step_closure~ :: ~card V~ rounds reach a fixed point.
- ~closure_le_of_fixed~ :: ~closure L~ is the least fixed point above
  ~L~, so a frontier walk and a round-by-round pass label the same set.
- ~closure_empty~ :: an empty seed stays empty when every ring has at
  least two vertices.
- ~closure_sound~ :: every vertex the closure adds lies on a ring whose
  other vertices are in the closure.
- ~edgeRule_not_sound~ and ~closure_twoRings~ :: the edge-sharing rule
  is unsound on a five-vertex instance. The rings are ~{0, 1, 2}~ and
  ~{0, 1, 3, 4}~ on ~Fin 5~, with ~{0, 1, 2}~ labelled. The edge rule
  labels ~3~, then the rest of the four-ring. The all-but-one closure
  adds nothing.

The file does not show that the C++ frontier bookkeeping computes
~step~. Catch2 in ~tests/test_cage_affiliation.cpp~ covers the C++
identity on a crystal, the refill of a single vacancy, and the
structural zero. The algorithm is
[[file:../explanation/ring-completion.org][Ring-adjacent completion]].

* Stacking planes

=lean/DseamsProofs/Stacking.lean= models ~ring::stackingPlanes~ and
~topoparam::tumLayerStack~. A basal ring of a passing HC pair is a
hexagonal plane. A ring that passes the DDC equatorial test is a cubic
plane. HC-affiliated rings are excluded from equatorial candidacy, so
the two plane sets are disjoint (~basal_equatorial_disjoint~). A layer
letter depends only on the two plane counts in that bin. The file does
not show that the C++ basal test matches a physical ice bilayer.

* Guest occupancy

=lean/DseamsProofs/Occupancy.lean= models ~site::guestOccupancy~,
~site::guestOccupancyInside~ and ~site::shellRings~. A closed shell is
a non-empty face list whose faces have length at least 3
(~empty_not_closed~). A radius assignment stays inside its radius
(~radius_within~). A point on a face, or reached by an odd number of
crossings, is inside (~on_face_inside~, ~odd_inside~). An empty ring
is not a capped shell (~empty_not_capped~).

* Build

Toolchain pin: =lean/lean-toolchain= (~leanprover/lean4:v4.15.0~).
Mathlib pin: =lean/lakefile.toml~ (revision ~v4.15.0~). Install
[[https://github.com/leanprover/elan][elan]], then:

#+begin_src bash
cd lean
lake exe cache get
lake build
#+end_src

~lake exe cache get~ fetches the Mathlib oleans. ~lake build~
type-checks =DseamsProofs=.
