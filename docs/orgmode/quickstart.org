In this tutorial you will analyze the ice structure of a water simulation
trajectory using d-SEAMS. By the end you will have classified every molecule
as cubic ice, hexagonal ice, or liquid water.

* Classify ice with the Trajectory class

The high-level ~Trajectory~ class handles trajectory reading, neighbour list
construction, and hydrogen bond computation automatically. This is the
recommended way to use d-SEAMS from Python.

The example trajectory ships with the repository at
~input/traj/exampleTraj.lammpstrj~. It contains 750 atoms (250 water molecules
with atom types 1=H and 2=O) in a periodic box.

#+begin_src python
from pydseamslib import Trajectory

traj = Trajectory("input/traj/exampleTraj.lammpstrj")
print(f"Loaded {traj.n_atoms} atoms, box: {traj.box}")

ice_types = traj.classify_chill_plus()
for ice_type, count in sorted(ice_types.items()):
    print(f"  {ice_type}: {count}")
#+end_src

You should see 250 oxygen atoms classified into cubic, hexagonal, interfacial,
and water categories.

The ~Trajectory~ class builds the neighbour list and hydrogen bond network
lazily on first access. You can also access them directly:

#+begin_src python
print(f"Neighbours per atom: {len(traj.neighbor_list[0]) - 1}")
print(f"H-bonds per atom: {len(traj.hbonds[0]) - 1}")
print(f"Number of rings found: {len(traj.rings)}")
#+end_src

* Low-level API (step by step)

For full control over each analysis step, use the ~_core~ module directly.

** Read a LAMMPS trajectory

#+begin_src python
from pydseamslib import _core

# Read frame 1 from the trajectory, selecting oxygen atoms (type 2).
# isSlice=False means we read the full box (coordLow/coordHigh are ignored).
cloud = _core.readLammpsTrjreduced(
    filename="input/traj/exampleTraj.lammpstrj",
    targetFrame=1,
    typeI=2,       # oxygen atom type in the LAMMPS file
    isSlice=False,
    coordLow=[0, 0, 0],
    coordHigh=[0, 0, 0],
)

print(f"Read {cloud.nop} oxygen atoms")
print(f"Box dimensions: {cloud.box}")
#+end_src

You should see 250 oxygen atoms and a box with three positive dimensions.

** Build the neighbour list

d-SEAMS builds neighbour lists based on a distance cutoff. For water, 3.5
Angstroms captures the first coordination shell.

#+begin_src python
# Build a neighbour list for oxygens within 3.5 Angstroms
nList = _core.neighListO(rcutoff=3.5, yCloud=cloud, typeI=2)

print(f"Neighbour list has {len(nList)} entries (one per atom)")
# Each entry is a list of atom IDs: [self, neighbour1, neighbour2, ...]
print(f"Atom 0 neighbours: {len(nList[0]) - 1}")
#+end_src

** Compute hydrogen bonds

The hydrogen bond network is built by re-reading the trajectory (to access
hydrogen positions) and applying geometric criteria to the oxygen neighbour
list.

#+begin_src python
# Build the hydrogen bond network.
# Htype=1 is the hydrogen atom type in the LAMMPS file.
hbonds = _core.populateHbonds(
    filename="input/traj/exampleTraj.lammpstrj",
    yCloud=cloud,
    nList=nList,
    targetFrame=1,
    Htype=1,
)

print(f"H-bond list has {len(hbonds)} entries")
# Count average number of H-bonds per oxygen
total_hbonds = sum(len(hb) - 1 for hb in hbonds)  # subtract self from each
avg_hbonds = total_hbonds / len(hbonds)
print(f"Average H-bonds per oxygen: {avg_hbonds:.2f}")
#+end_src

In bulk water/ice you should see roughly 3.5-4.0 hydrogen bonds per oxygen.

** Run CHILL+ classification

CHILL+ classifies each molecule by computing bond-order correlations between
neighbours. The function modifies the point cloud in-place, populating the
~c_ij~ field on each point.

#+begin_src python
# Compute CHILL+ bond-order correlations
cloud = _core.getCorrelPlus(yCloud=cloud, nList=nList, isSlice=False)

# Check that atoms now have correlation data
n_classified = sum(1 for pt in cloud.pts if len(pt.c_ij) > 0)
print(f"Atoms with bond-order data: {n_classified}/{cloud.nop}")
#+end_src

** Print ice type statistics

After CHILL+ correlation, each atom has a list of ~Result~ objects in ~c_ij~.
Each result contains a ~classifier~ (the bond type) and a ~c_value~ (the
correlation value). The ~iceType~ field on each point gives the final
classification.

#+begin_src python
# Write the full CHILL+ classification to disk and get the typed cloud back.
# This writes an output file and classifies each atom.
cloud = _core.getIceTypePlus(
    yCloud=cloud,
    nList=nList,
    path=".",
    firstFrame=1,
    isSlice=False,
    outputFileName="ice_classification.dat",
)

# Count ice types from the iceType enum on each atom
from collections import Counter

ice_counts = Counter()
for pt in cloud.pts:
    ice_counts[str(pt.iceType)] += 1

print("Ice type statistics for frame 1:")
for ice_type, count in sorted(ice_counts.items()):
    print(f"  {ice_type}: {count} atoms")
print(f"  Total classified: {cloud.nop} atoms")
#+end_src

The output file ~ice_classification.dat~ contains per-atom classifications that
you can load into visualization tools.

* Verify

After running the tutorial you should have:

1. A ~cloud~ object with ~nop~ equal to 250 (one entry per oxygen)
2. A neighbour list with 250 entries, each oxygen having roughly 4 neighbours
3. A hydrogen bond network with similar connectivity
4. Bond-order correlation data on most atoms
5. An output file ~ice_classification.dat~ with per-atom ice types

If any step fails, check that:

- The trajectory path is correct (run from the repository root)
- Atom types match your trajectory (type 2 = oxygen, type 1 = hydrogen)
- The cutoff (3.5 A) is appropriate for your water model
