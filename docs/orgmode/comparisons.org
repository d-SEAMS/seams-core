Head-to-head results that are already in the supplied examples. Each link is the
page that records the numbers. The suite tests named here are the ones
that recompute them.

The summary table is written at build time from the CSVs under
~docs/data/comparisons/~. Those files are copies of the benchmark
commits named above the table. A timed row names the comparator
version, the thread count, the repeat count and the core count.
