#+TITLE: OpenMP target offload
#+OPTIONS: toc:nil num:nil

Build the Steinhardt kernel and the TUM ice score for an NVIDIA GPU.
This is separate from the gpulite resident-batch path. Device CHILL+
is not included in this build.

Configure with an NVIDIA HPC compiler:

#+begin_src bash
export CXX=nvc++
meson setup build-offload --buildtype=debugoptimized \
  -Dwith_openmp_offload=enabled \
  -Dwith_mpi=disabled \
  -Dwith_gpulite=disabled
meson compile -C build-offload
#+end_src

The configure summary must report ~OpenMP target offload: YES~. The
compiler must support ~target teams distribute parallel for~ and have
access to a CUDA toolkit compatible with the installed driver. Clang
with libomptarget can use
~-fopenmp-targets=nvptx64-nvidia-cuda~.

* Runtime

~SEAMS_OFFLOAD=0~ forces the host path in an offload build. Unset, or
any value other than ~0~, uses the device when
~omp_get_num_devices() > 0~. Run ~seams --features~ to see whether
your binary includes OpenMP target offload.
