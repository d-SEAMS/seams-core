#+TITLE: Classify a dump
#+OPTIONS: toc:nil num:nil

You have a LAMMPS water dump and want counts. Flags and the full
surface live on [[file:../reference/cli.org][seams CLI]]. Measured
numbers for the in-tree mixed frame live in
[[file:../tutorials/bulk-ice.org][the mixed TIP4P tutorial]].

* One frame

#+begin_src bash
seams read FILE
seams chill-plus FILE --cutoff 3.5 --type 2
seams cages FILE --type 2
seams rdf FILE --type 2 --cutoff 10
#+end_src

The same flags on the bundled multi-type frame:

#+begin_src bash
seams read input/traj/il_tiny.lammpstrj
seams chill-plus input/traj/il_tiny.lammpstrj --cutoff 3.5 --type 2
seams cages input/traj/il_tiny.lammpstrj --type 2
seams rdf input/traj/il_tiny.lammpstrj --type 2 --cutoff 10
#+end_src

~chill~ is the original CHILL rule. ~chill-plus~ is the published CHILL+ rule: exactly four neighbours inside the cutoff, q3 over the four nearest, and the Table 1 neighbour test.
~chill_plus~ is a CLI alias of ~chill-plus~.
~ovito-chill+~ is the OVITO 3.17.2 rule (exactly four neighbours inside the cutoff, q3 over the whole shell, neighbour test off).
~--rule ovito-chill+~ selects it on ~chill-plus~, and a YAML or Lua file with ~rule:~ or ~rule =~ is a ~--rule~ value.
~CHILL_PLUS_RULE~ in the environment or in ~seams.env~ is the same string when ~--rule~ is absent.
Both bond every pair closer than ~--cutoff~ (~--graph cutoff~, the default).
~--graph mutual~ uses the mutual four nearest neighbours instead.

* Type

~--type 0~ (default) guesses type 2 then type 1. Mixed water dumps in
this tree use type 2 oxygen. Single-site mW dumps use type 1. A
mixed-type dump that is not that guess needs ~--type I~; see
[[file:ionic-liquid.org][Ionic-liquid dumps]]. ~--type~ is that load
filter, not the neighbour mask. AgI, kaolinite, INP and brine
dumps keep substrate and ions out of the four neighbours with
~--water-types~ (OW LAMMPS types). That flag loads the mixed
frame and scores ice on those types only.

#+begin_src bash
seams chill-plus FILE --water-types 1
seams cages FILE --graph seeded --water-types 1
seams ions FILE --ion-types 3,4 --water-types 1
#+end_src

The same flags on the bundled multi-type frame:

#+begin_src bash
seams chill-plus input/traj/il_tiny.lammpstrj --water-types 1
seams cages input/traj/il_tiny.lammpstrj --graph seeded --water-types 1
seams ions input/traj/il_tiny.lammpstrj --ion-types 3,4 --water-types 1
#+end_src

~--family~ defaults to ~waterIce~. ~chill~ / ~chill-plus~ / ~cages~
refuse every other family. A triclinic dump uses the stored tilt;
see [[file:sheared-cells.org][Sheared cells]].

#+begin_src bash
seams chill-plus FILE --type 2
seams cages input/traj/mW_cubic.lammpstrj --type 1
#+end_src

The same flags on the bundled multi-type frame:

#+begin_src bash
seams chill-plus input/traj/il_tiny.lammpstrj --type 2
#+end_src

* Frame range

Frames are 1-based. ~--last~ is inclusive. ~--jobs~ walks the range
via ~forEachLammpsFrame~ (~--jobs 1~ is serial).

#+begin_src bash
seams chill-plus FILE --frame 1 --last 10 --jobs 4
#+end_src

The same flags on the bundled multi-type frame:

#+begin_src bash
seams chill-plus input/traj/il_tiny.lammpstrj --frame 1 --last 10 --jobs 4
#+end_src

* Bond graph for cages

#+begin_src bash
seams cages FILE --graph seeded
seams cages FILE --graph seeded --complete
seams cages FILE --graph cutoff --cutoff 3.5
seams cages FILE --graph knn -k 4
seams cages FILE --graph knn-union -k 4
#+end_src

The same flags on the bundled multi-type frame:

#+begin_src bash
seams cages input/traj/il_tiny.lammpstrj --graph seeded
seams cages input/traj/il_tiny.lammpstrj --graph seeded --complete
seams cages input/traj/il_tiny.lammpstrj --graph cutoff --cutoff 3.5
seams cages input/traj/il_tiny.lammpstrj --graph knn -k 4
seams cages input/traj/il_tiny.lammpstrj --graph knn-union -k 4
#+end_src

~seeded~ is the CLI default: mutual four-nearest seeds, union
completions. ~--complete~ then runs ~ring::ringAdjacentCompletion~
on those labels. On a perfect cubic crystal the four graphs coincide.
