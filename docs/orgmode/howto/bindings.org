#+TITLE: Build the language fronts
#+OPTIONS: toc:nil num:nil

The nanobind module =dseams._core= is built in this repository when
nanobind is found. R and Julia call =libseams_lang=, which is built
with the engine and does not reimplement the classifiers. The released
Frame package remains [[https://github.com/d-SEAMS/PydSEAMSlib][PydSEAMSlib]].
The Lua module in this tree is [[file:lua.org][require("dseams")]].

* Python

#+begin_src bash
meson setup build -Dwith_python=true
meson compile -C build
#+end_src

~dseams._core~ links the in-tree ~libseams~. A missing nanobind uses
~subprojects/nanobind.wrap~. The default ~pixi run setup~ leaves
~with_python~ at its Meson default, which is true.

~import dseams~ is that module. ~Frame.set_frame~ stores coordinates.
~from_ase~ returns positions and a LAMMPS cell. ~neighbours~, ~rings~,
~q4q6~, and ~chill_plus~ are the calls in the Python recording. The
released Frame package on the [[file:../reference/python-frame.org][Python Frame]] page stays ~pydseams~.

#+begin_src python
>>> import numpy as np
>>> import dseams
>>> def ice():
...     xyz, edges, reading = [], [], False
...     handle = open("input/traj/ice1h.lammpstrj")
...     try:
...         while True:
...             line = handle.readline()
...             if line == "":
...                 break
...             if line.startswith("ITEM: BOX BOUNDS"):
...                 edges = []
...                 for _ in range(3):
...                     lo, hi = handle.readline().split()[:2]
...                     edges.append(float(hi) - float(lo))
...             elif line.startswith("ITEM: ATOMS"):
...                 reading = True
...             elif reading:
...                 parts = line.split()
...                 if len(parts) < 5:
...                     break
...                 xyz.append([float(v) for v in parts[2:5]])
...     finally:
...         handle.close()
...     return xyz, edges
>>> xyz, edges = ice()
>>> frame = dseams.Frame()
>>> frame.set_frame(np.asarray(xyz), np.asarray(edges))
>>> frame.count()
128
>>> int(frame.neighbours(3.5)[0][-1])
512
>>> int(frame.rings(3.5, 6)[2][6])
256
>>> round(float(frame.q4q6(3.5)[1].mean()), 6)
0.625855
>>> int(frame.chill_plus()[1][1])
128
>>> from ase import Atoms
>>> pos, box = dseams.from_ase(Atoms(symbols=["O"] * len(xyz), positions=xyz, cell=edges, pbc=True))
>>> frame.set_frame(pos, box)
>>> int(frame.chill_plus()[1][1])
128
#+end_src

* R

#+begin_src bash
export SEAMS_INCLUDE="$PWD/bindings/cxx"
export SEAMS_LIBDIR="$PWD/bbdir/bindings"
export LD_LIBRARY_PATH="$SEAMS_LIBDIR:$PWD/bbdir/src${LD_LIBRARY_PATH:+:$LD_LIBRARY_PATH}"
R CMD INSTALL --preclean bindings/r/dseams
#+end_src

The package needs ~cpp11~ and ~RcppEigen~.
With ~SEAMS_LIBDIR~ and ~SEAMS_INCLUDE~ set, it links that ~libseams_lang~; ~configure~ stops if ~seams_lang.h~ is not in ~SEAMS_INCLUDE~.
~--preclean~ runs ~cleanup~ first, as ~R CMD INSTALL~ builds the directory in place and would reuse objects from an earlier install of the other kind.
Without them, ~configure~ runs ~tools/vendor.sh~ and the package compiles its own copy of the engine, so ~R CMD INSTALL bindings/r/dseams~ works with no Meson build.
The engine is not a CRAN system library, and ~dseams~ is not on CRAN yet, so this is a source package you build from a seams-core checkout.
~R CMD build bindings/r/dseams~ makes a source tarball that carries the engine and installs without the checkout.

* Julia

CxxWrap is not linked.
~libcxxwrap_julia~ is not in the pixi or Nix closure, and building it pulls a Julia sysimage into the link.
The front that ships is ~ccall~:

#+begin_src bash
export SEAMS_LANG_LIB="$PWD/bbdir/bindings/libseams_lang.so"
export DSEAMS_ROOT="$PWD"
julia --project=bindings/julia/Dseams bindings/julia/Dseams/dev/develop_jll.jl
julia --project=bindings/julia/Dseams bindings/julia/Dseams/test/runtests.jl
#+end_src

~Dseams~ and ~libseams_jll~ are not in the General registry yet, so
~Pkg.instantiate()~ alone cannot resolve the JLL.
~dev/develop_jll.jl~ develops the stand-in in ~dev/libseams_jll~, which
has no binaries, and then instantiates; ~SEAMS_LANG_LIB~ names the
engine. ~packaging/yggdrasil/L/libseams~ is the recipe for the real JLL.

* Lua and Fennel

~-Dwith_lua=auto~ builds ~dseams_core.so~ for Lua 5.4 and for LuaJIT.
~require("dseams")~ and ~(require :dseams)~ call ~seams.h~.
The how-to is [[file:lua.org][Lua and Fennel]].
~meson test lua_examples~ runs the example scripts.

* q4 and q6

The cutoff-shell solid-harmonic kernel is ~seams_q4q6~ in ~seams.h~ and ~seams_frame_q4_q6~ in =libseams_lang=. The flat name ~seams_q4_q6~ lives in ~src/include/internal/seams_c_api.h~ and is not installed.
Python is ~q4_q6~ in =bindings/python/chill_plus.py= (~SEAMS_LANG_LIB= selects the library).
R and Julia export ~q4_q6~.
The CLI command is ~seams steinhardt~. ~--l~ names the degrees (default ~4,6~). ~--l 3,12~ asks for the hydrate pair.
