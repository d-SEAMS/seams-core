#+TITLE: Performance
#+OPTIONS: toc:nil num:nil

Head-to-head times for the neighbour list, primitive rings, local
\(q_6\), CHILL+, cages, and PTM. The other codes are OVITO, freud,
mdapy, ClavisCage, cycless, and SQQ. PTM is the OVITO polyhedral
template match. Linkcell scaling is the cutoff-ring list against the
older cell list.

The 884736-molecule sitting is ice and a TIP4P/ice liquid, at 1, 2, 4
and 8 threads. The rivals on that file are rings-statistics-matter,
freud, mdapy, pyscal3, PLUMED, vesin and OVITO. The file is the sitting
written at ~2ed49e87~. On the liquid, freud \(q_6\) is a hard-cutoff
rounding gap, PLUMED is a rational-switch gap, and CHILL+ matches a
counted subset of the molecules. The generated note prints those three
CSV tokens.

The figure is an SVG of median
time against thread count, ice and liquid side by side.

With only ~OMP_NUM_THREADS~ set and a team as wide as the host mask,
the library places each worker on one cpu of that mask for the call and
restores that affinity afterwards. ~SEAMS_PIN=0~ leaves placement to the host. A narrower
mask, ~OMP_PLACES~, ~GOMP_CPU_AFFINITY~, ~KMP_AFFINITY~, or a caller
already bound to one cpu is respected, and placement adds no cpu
outside the launch mask.
Concurrent copies of the program share the mask in disjoint slices
instead of stacking on the same cpus. The threading page records the
rule. On 8 cores the unbound 110592-molecule C API, one fresh process,
three warm-ups and one timed call, is about 2.4 ms for neighbours and
about 2.4 ms for \(q_6\).

The tables are the frozen tables in =docs/records=, rendered from the
benchmark records dataset (=docs/records/README.md= names the revision).
