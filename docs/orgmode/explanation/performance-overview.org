The operation string is the string the record stored. It is a different call on different pages.

On the release-candidate sitting, \(q_4\) and \(q_6\) are one Steinhardt call, and the rings row is ~seams_frame_rings~ on the cutoff graph: the neighbour list and the search together. The 884736-molecule rings row is that same call in the other sitting. The pool-audit rings kernel on the thread-controls page is ~ringNetwork~ after the neighbour graph already exists. Those ring times are separate measurements.

The release-candidate PLUMED worker sets ~OMP_NUM_THREADS~ and does not set ~PLUMED_NUM_THREADS~. The head-to-head page holds the other PLUMED \(q_6\) rows.
