#+TITLE: The C API
#+OPTIONS: toc:nil num:nil

=include/seams.h= is ABI 1 of =libseams=. Language bindings and engine
plugins include that header and link =libseams=. =seams.h= includes
=seams_version.h=. The headers under =src/include/internal= belong to
the engine.

* Handles

The public types are opaque. =seams_system= is one frame.
=seams_neighbours= is one neighbour list. =seams_rings= is one set of
primitive rings. =seams_cage_set= is hexagonal and double-diamond
membership. =seams_brine= is one planar ice front. =seams_topo= is the
topological fingerprint of one bonded frame. No public struct has
fields.

Each handle comes from a create, build, find, or analyse call and is
released by the matching destroy function. =seams_system_create=
starts an empty frame. A null pointer passed to a destroy function is
ignored. A second destroy of the same pointer records "double
destroy" and frees nothing.

The library copies every array a caller passes in. A handle built
from a frame holds its own copy, so the frame may be destroyed
first. Results are written into caller buffers. Strings the library
returns are static, or they stay owned by the library.

=seams_neighbours_csr= is the ABI 1 exception. It is marked
=SEAMS_DEPRECATED= and returns offset and column pointers owned by
the neighbour handle. Those pointers remain valid until
=seams_neighbours_destroy=. The columns omit the self index.
=seams_neighbours_copy= writes the same CSR into caller buffers. A
null buffer queries the length.

* Status and errors

A call that can fail returns =seams_status=. Zero is =SEAMS_OK=. The
other codes are =SEAMS_ERR_NULL=, =SEAMS_ERR_RANGE=, =SEAMS_ERR_BOX=,
=SEAMS_ERR_ARG=, =SEAMS_ERR_STATE=, =SEAMS_ERR_NOMEM=, and
=SEAMS_ERR_INTERNAL=.

A failing call stores a detail string. =seams_last_error= and
=seams_last_error_message= return that thread-local string. When the
call had a handle, =seams_handle_error= returns the copy stored on
the handle. A null handle argument returns the thread-local string.
The handle string survives a later call on a different handle. The
next call that takes the same handle non-const clears the handle
string on entry. A successful call on this thread leaves the
thread-local string empty. A const call writes the handle string
only when it fails, so a successful const call leaves the previous
failure in place.

No C++ exception crosses this boundary. Each one is caught and
returned as a status. The version and name queries, the destroy
functions, and the ABI 1 counts =seams_system_count=,
=seams_neighbours_count=, and =seams_rings_count= return no status.
A null handle gives those counts the value 0.

* Lengths

Caller buffers take a =size_t= length. A null output buffer with a
length pointer queries the required count and returns =SEAMS_OK=. A
short buffer returns =SEAMS_ERR_RANGE=, leaves that buffer
untouched, and still writes the required count.

ABI 1 kept an =int= atom count on =seams_system_set_frame= and
=seams_system_set_ortho=. It also kept =seams_chill_plus=,
=seams_q4q6=, =seams_rings_labels=, and =seams_rings_histogram=
without a caller-supplied length. The length-checked spellings are
=seams_system_set_atoms=, =seams_system_natoms=,
=seams_neighbours_nrows=, =seams_rings_nrings=,
=seams_chill_plus_n=, =seams_q4q6_n=, =seams_rings_labels_n=, and
=seams_rings_histogram_n=. A count that does not fit in the frame's
integer width is =SEAMS_ERR_RANGE= on the =size_t= entry as well.

* ABI

=SEAMS_ABI= is 1, and =seams_abi= returns it. The number stays 1
while every shipped function keeps its signature and every shipped
enumerator keeps its numeric value. New functions and new
enumerators are appended. =SEAMS_GRAPH_CUTOFF= is 0,
=SEAMS_GRAPH_MUTUAL= is 1, and =SEAMS_GRAPH_SEEDED= is 2. A later
struct, if one is added, starts with a =uint32_t= size set by the
caller to the size of the struct that caller compiled. The library
reads only the prefix that size covers.

=SEAMS_API= marks every exported symbol. The rest of the library is
hidden. =SEAMS_VERSION_MAJOR=, =SEAMS_VERSION_MINOR=,
=SEAMS_VERSION_PATCH=, =SEAMS_VERSION_STRING=, and
=SEAMS_VERSION_NUMBER= are the version of the header.
=seams_version= returns the =SEAMS_VERSION_NUMBER= the library was
built with, packed as =(major << 16) | (minor << 8) | patch=.
Both sides carry the project version. The header and the library disagree when
=seams_version= and =SEAMS_VERSION_NUMBER= differ.

* Threads

Distinct handles may run on distinct threads at the same time. One
non-const call owns its handle until it returns. Const calls on one
handle may run together while that handle has no non-const call in
progress. When threads share a handle, read the failure with
=seams_last_error_message=. The handle slot holds whichever failure
landed last.

=seams_ql=, =seams_q4q6=, =seams_q4q6_n=, =seams_q6bar=, and
=seams_steinhardt= keep their =q_lm= work arrays on the calling
thread, so those calls may run at the same time on different
handles. =seams_set_num_threads= is process-global. Call it while
no analysis is running. The stored width is the OpenMP team every
later analysis requests. A positive argument sets that width. Zero
restores the width captured at first use. A negative width is
=SEAMS_ERR_RANGE=.

=seams_chill=, =seams_chill_plus=, and =seams_chill_plus_n= write
each atom's label into the stored frame. Coordinates, the cell,
types, and ids stay as they were. A load replaces the stored frame,
and on failure the previous frame stays. Every other analysis
clears the error slot and leaves coordinates, the cell, types, and
ids unchanged.

* Coordinates

Coordinates and cutoffs are Angstrom. The cell is nine doubles:
origin =ox, oy, oz=, edge lengths =lx, ly, lz=, then the tilts
=xy, xz, yz=. A zero tilt is orthorhombic.

A cutoff neighbour is kept when the squared minimum-image distance
is strictly below the cutoff squared. =seams_neighbours_build= with
=SEAMS_GRAPH_MUTUAL= keeps the four nearest neighbours inside
cutoff + 1.5. That call rejects =SEAMS_GRAPH_SEEDED=. Cage searches
accept the seeded graph: mutual seeds, then union completions. A
zero neighbour count on a seeded search selects 4.

A non-positive =shell_rmsd= passed to =seams_system_symmetry=
selects the library ceiling, the scale-free second-shell residual
0.15. The label is 0 for ice Ih, 1 for ice Ic, 2 for stacking
disorder, and -1 when the shell does not match.

=seams_q6bar= counts finite values strictly above =ice_cut=. The
nucleation census uses 0.36. The mean and the median ignore
non-finite values, and an empty finite set stores 0.

A trajectory loop calls =seams_system_set_atoms= for the first
frame and =seams_system_set_positions= for each later frame of the
same length. The later call writes coordinates.

=seams_cages= is the same search as =seams_cages_find=.
=seams_signature_cages= is the same search as =seams_cages_signature=.
=seams_steinhardt= is =seams_ql= on the cutoff graph. The mutual
graph of =seams_ql= reads the four nearest neighbours inside
cutoff + 1.5. =seams_signature_cages_edge= takes the same census
with an explicit face-edge window. A null or empty window keeps
2.65 to 3.15 in the coordinate units of the file. The text =none=
leaves the cage bound to the face census.

=seams_system_read= reads CON when readcon is linked. Every other
file goes through chemfiles when that library is linked. XYZ and
LAMMPS dump also have a native reader, and a tilted dump is stored
as the nine-number cell above. A negative type filter keeps every
atom. Zero guesses the oxygen species. A positive value keeps that
species number.

The bond rows of the 2015 CHILL+ rule and of the OVITO modifier are
on [[file:chill-plus-rules.org][CHILL+: the published rule and the
OVITO rule]].

* OVITO and freud

d-SEAMS keeps a cutoff neighbour when the minimum-image distance is
strictly below the cutoff. Freud uses the same open ball. OVITO's
uniform bond modifier also keeps a pair that sits on the cutoff.
Two particles 3.5 Å apart are a bond in OVITO, and d-SEAMS and freud
leave that pair out. A separation of 3.5 Å minus 1e-4 Å is a
neighbour in all three.

=seams_neighbours_knn= writes an undirected row. With the mutual
flag clear, an edge is kept when either atom lists the other among
its k nearest. With the flag set, both atoms must list each other.
Freud and OVITO return the directed k nearest. Closing those
directed lists the same way reproduces the C rows. Four points on a
line at 0, 1, 3, and 6 Å, with k = 1, put both adjacent indices in
the one-way row of the point at 1 Å. The mutual row of that point
holds only the point at 0 Å.

Local =q_l= is the norm of the spherical harmonic of the cutoff
shell. q6-bar is the Lechner-Dellago norm of the mean =q_6m=, and
the atom itself is in that mean. Three oxygens at (0, 0, 0),
(2, 0, 0), and (0, 2, 0), with a cutoff of 2.5 Å, follow that mean.
The value differs from the mean of the scalar q6 numbers. Two
oxygens 2 Å apart give q6 = 1. An empty shell is stored as 0.
Freud 3.6 stores =q_l= in float32. Rounding the same =q_6m= to
float32 before the norm is the residual against a float64 sum.

=seams_chill_plus= with =SEAMS_CHILL_OVITO= averages =q_lm= over
every neighbour inside the cutoff and uses the modifier's open
edges. =SEAMS_CHILL_PUBLISHED= is Nguyen and Molinero, J. Phys.
Chem. B 2015, equation 1: the four closest neighbours, with
inclusive edges. =seams_chill= is Moore's four-neighbour rule.
=SEAMS_CHILL_PUBLISHED= uses the inclusive =c_ij= edges, and
=SEAMS_CHILL_OVITO= uses the open edges.

=seams_system_symmetry= and OVITO polyhedral template matching, with
the cubic and hexagonal diamond structures enabled and an RMSD
cutoff of 0.1, name the same atoms on ice Ih and on the generated
ice Ic lattice. That lattice sits on the cubic-diamond template,
with RMSD below 1e-6. The ice Ih file stays under 0.1. Where the
two labels differ, a kernel crystal that the template matcher calls
other has RMSD above 0.1, and a template-matcher diamond that the
kernel leaves unlabeled has RMSD below 0.1. The kernel ceiling on
that comparison is the second-shell residual 0.15.

=seams_rdf= counts each unordered like-species pair once and
normalises by =N(N-1)/2=. OVITO, and freud in its exact mode,
normalise the directed histogram by =N^2=. The histograms differ by
=N/(N-1)=. Multiplying the d-SEAMS values by =(N-1)/N= recovers the
directed normalisation, including the bin centers. The coordination
number from =seams_coordination= carries the same factor, so the
neighbour degree is that integral times =(N-1)/N=. On the 64-atom
ice Ic cell the factor is 64/63. A degree of 4 is an unscaled
coordination of 256/63.

Freud refuses an =r_max= past half the shortest edge. d-SEAMS still
bins minimum-image distances on a 10 Å cell out to 6 Å. A float32
distance can move a pair across one bin edge.

A pair placed 0.1 Å inside opposite faces of a 10 Å cell whose
origin is (2, 2, 2) Å has a minimum-image distance of 0.2 Å. That
pair is a cutoff neighbour in d-SEAMS, freud, and OVITO.

* Install

The install provides =seams.h=, =seams_version.h=, and the C++
wrapper =seams.hpp=. The shared library is =libseams.so= on Linux,
=libseams.dylib= on macOS, and =seams.dll= on Windows. =seams.pc=
is the pkg-config file. =seams-config.cmake= and
=seams-config-version.cmake= are installed under =cmake/seams/= in
the library directory.

#+begin_src sh
pkg-config --cflags --libs seams
#+end_src

=examples/c/quickstart.c= builds against that install. The Meson
file in =examples/c= uses =dependency('seams')=. The CMake file uses
=find_package(seams)= and the imported target =seams::seams=.
