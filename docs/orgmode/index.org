* Overview

d-SEAMS 2.14 reads a molecular-dynamics trajectory and names the ice in it.
~libseams~ is the library: CHILL+, cages, primitive rings, and \(q_6\) share one cutoff neighbour list.
The ~seams~ command, the C and C++ APIs, and the language bindings call that library.

Install the engine with one line.

#+begin_src bash
meson setup build && meson compile -C build
#+end_src

Ten lines classify the cubic cell shipped in ~input/traj~.

#+begin_src bash
dump=input/traj/mW_cubic.lammpstrj
seams read "$dump" --type 1
seams chill-plus "$dump" --type 1 --cutoff 3.5
seams ovito-chill+ "$dump" --type 1 --cutoff 3.5
seams rings "$dump" --type 1 --cutoff 3.5
seams steinhardt "$dump" --type 1 --l 6
seams cages "$dump" --type 1
seams cages input/traj/genice_sI.lammpstrj --type 1 --signature 512 --cage-edge none
seams rdf "$dump" --pair-types 1,1 --cutoff 6 --bins 4
seams prisms "$dump" --type 1
#+end_src

The [[file:videos/index.org][videos]], the
[[file:user/howto/migrate-1x.org][1.x migration]], the
[[file:explanation/performance-h2h.org][performance tables]], and the
[[file:reference/release-2.14.org][2.14.0 notes]] are the rest of this
release.

d-SEAMS (Deferred Structural Elucidation Analysis for Molecular
Simulations) classifies ice in molecular-dynamics trajectories. This
repository is the C++ engine (~libyodaLib~) and the ~seams~ CLI.

The first classification is five lines. Install with
~pip install 'pydseamslib==2.14.0'~ for the Frame package, with conda-forge's
Meson toolchain, or with ~meson setup build && meson compile -C build~,
then run the Python and C programs on
[[file:getting-started/quickstart.org][the quick start]]. Both report 8 cubic molecules.

#+begin_src bash
seams read input/traj/ice1h.lammpstrj
seams chill-plus input/traj/ice1h.lammpstrj --cutoff 3.5
seams cages input/traj/ice1h.lammpstrj
#+end_src

2.14.0 ships ~libseams~ (~seams.h~), ~libseams_lang~, the C and C++
APIs, and the LAMMPS, OpenMM, PLUMED, and in-situ engines.
~gmx-seams~ reads the trajectory after ~gmx mdrun~.
Each language binding is its own repository, released with the same
version against this tag:

- Python: ~pydseamslib~ (~import dseams~, ~import pydseams~),
  [[https://github.com/d-SEAMS/PydSEAMSlib][PydSEAMSlib]]
- Lua and Fennel: LuaRocks ~dseams~, [[https://github.com/d-SEAMS/yodaStruct][d-SEAMS/yodaStruct]]
- R: ~dseams~, [[https://github.com/d-SEAMS/dseams-r][dseams-r]]
- Julia: ~Dseams~, [[https://github.com/d-SEAMS/Dseams.jl][Dseams.jl]]
- Rust: ~dseams-sys~ and ~dseams~, [[https://github.com/d-SEAMS/dseams-rs][dseams-rs]]
- Fortran: fpm ~dseams~, [[https://github.com/d-SEAMS/dseams-fortran][dseams-fortran]]

[[file:development/repositories.org][The repository map]] says what
lives where.

The header *Ecosystem* menu on every page jumps between the engine,
the bindings, and linkcell.

Build with a Nix flake (~nix build~, ~nix develop~) or with
~pixi run setup && pixi run build && pixi run test~.

* d-SEAMS 2.0 paper

The d-SEAMS 2.0 paper, its benchmark campaign, the record tables and
the reproduction rules are in a private paper repository. The
benchmark records and figure data are the Hugging Face datasets
=d-SEAMS/dseams2-benchmark-records= and =d-SEAMS/dseams2-paper-figure-data=.
The performance pages here show tables rendered from those records
(=docs/records/README.md= names the revision).
