#+TITLE: Use with AI assistants
#+OPTIONS: toc:nil num:nil ^:nil

The manual is published as HTML and as Markdown. An agent should read
the Markdown.

* Where the text is

Each page is two files. ~quickstart.html~ is the page a browser shows.
~quickstart.md~ is the same page without the navigation. The HTML head
links the Markdown as ~rel="alternate"~ with type ~text/markdown~, and
links ~llms.txt~ as ~rel="describedby"~.

https://docs.dseams.info/llms.txt is the index. Each entry points at a
Markdown file. https://docs.dseams.info/llms-full.txt is those pages in
one file, for a model with a long context. Fetch the index first.

The page menu can copy the Markdown, open it, or hand the Markdown URL
to a chat assistant.

* The skill

~skills/d-seams/SKILL.md~ in the seams-core repository follows the
[[https://agentskills.io/specification][Agent Skills]] format. It
covers install, the ~seams~ command, ~import dseams~, the C API in
~include/seams.h~, and the mistakes that waste a run: the atom type,
the 1.x command name, and which repository holds a language binding.

Put that file on the agent's skill path, or give the agent the URL of
this page and of ~llms.txt~.

* Install, then one cell

The engine is conda-forge ~libseams~, or ~meson setup build && meson
compile -C build~. Python is ~pip install 'pydseamslib==2.14.0'~ and
~import dseams~. The C and C++ headers ship with the engine.
[[file:install.org][Install the engine]] has the four methods. The
[[file:quickstart.org][quickstart]] classifies one cubic cell and
expects 8 cubic molecules.

* Context7

~context7.json~ at the repository root names the folders Context7
should read (the Org manual, the API and tutorial pages, the examples,
and the skill) and the trees it should skip (vendored subprojects,
tests, and generated HTML).

* Editing the repository

[[file:../development/index.org][Contributing]] and ~AGENTS.md~ are
the contract for a change to this repository. A binding change belongs
in that binding's repository.
