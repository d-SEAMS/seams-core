#+TITLE: Versions
#+OPTIONS: toc:nil num:nil ^:nil

Versions of every component that the records of the d-SEAMS 2.0 paper
built or called. The paper describes seams-core v2.12.0. A rerun at a
later release adds a row here and leaves the v2.12.0 rows in place.

* Engine and front ends

| component | version | notes |
|-----------+---------+-------|
| seams-core | v2.12.0 | v2.11.0 (~9f963b72~) with two patches; the first holds the ring, cage-affiliation, update, device and command-line changes with their tests, and the second sets the version to 2.12.0 |
| d-SEAMS 1 baseline | seams-core commit ~1c8efa38~ (2026-05-28) | between v2.0.1 and v2.1.0; walk enumeration, the pair-scan HC search followed by the DDC search, and the all-pairs index-ordered neighbour builder |
| PydSEAMSlib (Python, ~import pydseamslib~) | 2.11.1 on PyPI | the wheel wraps seams-core v2.11.0; the label tables and the head-to-head table use its sdist built with v2.12.0 as the seams-core subproject |
| yodaStruct (Lua, ~require("dseams")~) | v2.10.0 | a separately versioned front end that builds seams-core v2.10.0 |
| dseams-plumed (PLUMED action ~DSEAMS_CAGES~) | builds seams-core commit ~bdc9b74b~ | separate MIT module, [[https://github.com/d-SEAMS/dseams-plumed][d-SEAMS/dseams-plumed]] |
| LAMMPS compute ~compute dseams~ | in seams-core | ~extras/lammps/compute_dseams.cpp~ and ~compute_dseams.h~ |
| Lean development of the supplement | Lean toolchain v4.15.0 | the =lean/= folder of the supplementary archive, no other library |

The =lean/= directory of seams-core is a separate development (Lean
4.15.0 with Mathlib v4.15.0, see [[file:../contributing/lean.org][Lean proofs]]),
and the paper does not use it.

* Comparison codes

The head-to-head table of the paper (record ~h2h-2026-10-31~) and the
label tables call these versions. The pixi lock of dseams2_repro pins
OVITO, freud, GenIce2, cycless, pyscal3 and Snakemake. genice2-cage
comes from pip, and R.I.N.G.S. is built from its SourceForge archive.

| code | version | used for |
|------+---------+----------|
| OVITO Python module | 3.15.5 | CHILL+ and polyhedral template matching |
| freud | 3.5.0 | Steinhardt \(q_6\) and \(\bar q_6\) on the four nearest neighbours |
| GenIce2 | 2.2.13.3 | test lattices; its ring formatter calls cycless |
| cycless | 0.7 | shortcut-free rings and polyhedral cages |
| genice2-cage | 2.5.2 (pip) | the cage formatter, run once untimed on sI |
| analice2 | 2.2.13.3 | not used: it stops with an ~AttributeError~ on both the mW and the sI input |
| R.I.N.G.S. | rings-code 1.3.5 (SourceForge) | primitive ring census |
| pyscal3 | 3.3.2 | Steinhardt cross-check |
| Snakemake | 9.6.2 | the reproducibility workflow |
