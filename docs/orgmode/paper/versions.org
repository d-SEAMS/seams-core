Versions recorded for seams-core 2.14.0 in this repository.

carry the release string. [[file:benchmarks.org][Benchmarks]] is where
each record lives. [[file:reproduce.org][Reproduce]] is how to
regenerate it.

the version-pins page.

* Records and the machine fields they store

=benchmarks/paper-cells/sitting.csv= has 70 rows. Every row names
source commit =c2f0d10a6b9f25fc0a6caf7fc116649ec1e37db2=, an Intel Xeon
Processor (family 6, model 207, stepping 2), 8 cores, and affinity
=0-7=. The d-SEAMS rows set =version= to =seams 2.14.0=.

=benchmarks/paper-cells/rerun-main/report.txt= names a different
checkout: =source_commit 2914162cb8200dc1a5668a54d570130785ccef0c=,
=seams_version seams 2.14.0=, =cpu_model Intel(R) Xeon(R) Processor=,
=cpu_cores 8=, =affinity 0-7=.

=bench/omp-scaling/scaling.csv= does not name a CPU model or a commit.
Its =version= column is the string =before= or =after= on the dseams
rows, =mdapy 2.0.0= on the mdapy rows, and =pyscal3 4.1.0= on the
pyscal3 rows.
