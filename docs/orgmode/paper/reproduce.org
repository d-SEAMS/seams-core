#+TITLE: Reproduce
#+OPTIONS: toc:nil num:nil ^:nil

Install seams-core 2.14.0 and regenerate the benchmark files in this
repository. [[file:versions.org][Versions]] lists the pins.
[[file:benchmarks.org][Benchmarks]] names each record.
[[file:../howto/install.org][Install the engine]] is the full install.
[[file:../explanation/citation.org][Citation]] says how to cite the
2020 JCIM paper and the v2 engine paper.

* Install this tree

The meson project version is 2.14.0. ~seams --version~ prints that
string. The same string is the pin on
[[file:../howto/versions.org][Version pins]].

#+begin_src bash
git clone https://github.com/d-SEAMS/seams-core
cd seams-core
pixi run setup && pixi run build && pixi run test
#+end_src

A hand build of the same tree:

#+begin_src bash
meson setup bbdir --buildtype=release
meson compile -C bbdir -j2
./bbdir/seams read input/traj/exampleTraj.lammpstrj
#+end_src

The install page covers Python from PyPI (~pydseamslib~, import
~dseams~) and the Lua repository. The LAMMPS sources in this tree are
=extras/lammps/compute_dseams.cpp= and =compute_dseams.h=.
=extras/lammps/README.md= describes the compute. The PLUMED module is
[[https://github.com/d-SEAMS/dseams-plumed][dseams-plumed]].

* Regenerate the records

The root =Snakefile= writes the files under =benchmarks/paper-cells/=
and =bench/omp-scaling/=. The release binary those rules call is
=bbdir-release/seams= and =bbdir-release/src/libyodaLib.so=.
Two jobs:

#+begin_src bash
snakemake -j2 benchmarks/paper-cells/sitting.csv
snakemake -j2 benchmarks/paper-cells/tab-rings-214.csv
snakemake -j2 benchmarks/paper-cells/tab-ql-eq.csv
snakemake -j2 benchmarks/paper-cells/tab-neighbours.csv
snakemake -j2 benchmarks/paper-cells/tab-chill.csv
snakemake -j2 benchmarks/paper-cells/tab-cages.csv
snakemake -j2 benchmarks/paper-cells/tab-cli.csv
snakemake -j2 benchmarks/paper-cells/tab-lit.csv
snakemake -j2 benchmarks/paper-cells/tab-hop-stride.csv
snakemake -j2 benchmarks/paper-cells/tab-sym-eq.csv
snakemake -j2 benchmarks/paper-cells/symmetry-vs-ptm.csv
snakemake -j2 benchmarks/paper-cells/ptm-ice.csv
snakemake -j2 benchmarks/paper-cells/rerun-main/report.txt
snakemake -j2 bench/omp-scaling/scaling.csv
snakemake -j2 data/engines-e2e.csv
#+end_src

=paper_tables= writes the =tab-*= selections from =sitting.csv=.
=paper_rerun= (=scripts/rerun_main_text.py=) writes
=benchmarks/paper-cells/rerun-main/report.txt=.
=omp_scaling= (=scripts/omp_scaling.py=) writes
=bench/omp-scaling/scaling.csv=.
=engines_e2e= (=scripts/engines_e2e.py=) writes =data/engines-e2e.csv=.
[[file:../howto/paper-tables.org][Paper tables]] lists the table targets.

=bench/README.md= times =seams_bench=. The executable is
=bbdir-rel/bench/seams_bench=.

#+begin_src bash
meson setup bbdir-rel --buildtype=release -Ddebug=true -Dwith_tests=true
meson compile -C bbdir-rel -j2 seams_bench
OMP_NUM_THREADS=1 ./bbdir-rel/bench/seams_bench --case all --reps 1
#+end_src

The tutorial rules live in =docs/tutorials/Snakefile=. A rule name is
=interface=, =cages=, =rings=, =brine=, or =nucleation=.

#+begin_src bash
snakemake -j2 -s docs/tutorials/Snakefile rings
#+end_src

* Carried frames

The Meson test =seams_carried_frames_match_rebuild= runs
=tests/cli_carry.py=. It compares the JSON of a carried range with
~--rebuild~, ~SEAMS_CARRY=0~, and ~--jobs 2~ on
=input/traj/mW_cubic.lammpstrj= and =input/traj/dump-l.lammpstrj=.

#+begin_src bash
meson test -C bbdir -j2 seams_carried_frames_match_rebuild
#+end_src

[[file:../reference/cli.org][seams CLI]] lists when the command line
carries and when it rebuilds.

* Run the tests

#+begin_src bash
meson test -C bbdir -j2
#+end_src

* Reproduce the paper

Each row is one figure or table that seams-core produces for the
d-SEAMS 2.0 paper. =small= rows run in =meson test docs_paper_reproduce=.
=full= rows run in =meson test docs_paper_reproduce_full= when the build
is configured with =-Dpaper_full=true=. The command is =paper <topic>=,
which is =docs/tutorials/paper_science.py=, or a =seams= invocation.
The expected cell is the text that command prints. The regenerator
cell is the Snakemake rule or asv class that rebuilds the full record.
A comparison also names the committed head-to-head CSV, and the last
cell is a phrase that file contains.

The small ring, cage, interface, brine, and nucleation rows are the
unit-cell and three-frame drivers. The full rows read
=input/traj/mW_cubic.lammpstrj= (11 frames, frame 1 scored), the
GenIce repeats, =input/traj/interface_f0.lammpstrj=,
=input/traj/nacl_front.lammpstrj=, and the 148-frame figshare
nucleation trajectory. Head-to-head rows run the same census on
=input/traj/ice1h.lammpstrj= (128 molecules, 256 six-rings, q6
0.625855) or =input/traj/genice_sI.lammpstrj= (2 cages of \(5^{12}\),
40 vertices). The CSV phrase is the 4096-molecule agreement, not a
second timing.
