Benchmark records of seams-core 2.14.0 stored in this repository.
A number below is a cell of the named file. [[file:versions.org][Versions]]
gives the pins and the machine fields. [[file:reproduce.org][Reproduce]]
gives the Snakemake rule for each file.
[[file:../howto/paper-tables.org][Paper tables]] lists the same targets.
[[file:../howto/benchmarks.org][Benchmarks]] names the driver binaries.

by rule =paper_sitting= (=scripts/paper_sitting.py=). The ice rows are

* OpenMP scaling

=bench/omp-scaling/scaling.csv= is rule =omp_scaling=
(=scripts/omp_scaling.py=). The Snakefile comment on that rule says
the cell is 110592-molecule ice Ic at 1, 2, 4, and 8 threads. The
=check= column of the dseams rows records ~pairs=442368~ for
neighbours and ~six=221184~ for rings. Each row has =n= = 10.
The =version= strings are =before=, =after=, =mdapy 2.0.0=, and
=pyscal3 4.1.0=. The file does not name a release or a CPU.

=after= medians, milliseconds:

| operation | 1 thread | 8 threads |
|-----------+----------+-----------|
| neighbours | 10.234 | 2.121 |
| q4 | 15.310 | 2.626 |
| q6 | 15.915 | 2.692 |
| rings | 119.971 | 19.531 |

Eight-thread medians of the other codes in the same file: mdapy q4
13.388, mdapy q6 14.933, pyscal3 q4 22.184, pyscal3 q6 22.617.

=bench/README.md= describes =seams_bench= (neighbours, q3, q6, rings,
ice) and =bench/measure.py=. Those runs write under =bench/local/=,
which is gitignored. The committed scaling file is the record above.
