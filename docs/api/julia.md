# Julia

The Julia binding is the Julia package `Dseams`.

Install the current source as a Git dependency:

```bash
julia -e 'using Pkg; Pkg.add(url="https://github.com/d-SEAMS/Dseams.jl")'
```

Read the [Julia binding documentation](https://julia.dseams.info/) or
watch the [Julia walkthrough](https://docs.dseams.info/videos/embeds/julia.html).
