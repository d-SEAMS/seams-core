# R

The R package `dseams` is [d-SEAMS/dseams-r](https://github.com/d-SEAMS/dseams-r). It links `libseams_lang` (`bindings/cxx/seams_lang.h`). A source install compiles the seams-core tree named in `tools/seams-core.ref`.

```text
remotes::install_github("d-SEAMS/dseams-r")
```

The first classification is the {doc}`R tutorial </fronts/r>`.
