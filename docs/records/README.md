# Frozen benchmark tables

These tables and figures were rendered from the d-SEAMS 2.0 benchmark
records before the records moved out of this repository. A path such as
`benchmarks/rc3-sitting.csv` names a file of the Hugging Face dataset
`d-SEAMS/dseams2-benchmark-records` at revision
`3246502bec7bb0df04a9bb1855eac06efab0b7e7`, which holds the records, the
logs and the scripts that wrote them. `docs/source/conf.py` copies these
files into the Sphinx tree; they are not regenerated by the docs build.
