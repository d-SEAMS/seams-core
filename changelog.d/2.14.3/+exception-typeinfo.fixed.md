`gen::mic::RangeError` and `pore::BoxError` each have one default-visibility key function in libyodaLib, and `linkcell::Error` has its key function in linkcell's shared liblinkcell_eh. The C API, built with hidden visibility, therefore reports a minimum-image or linked-cell range failure as `SEAMS_ERR_RANGE` and a pore box failure as `SEAMS_ERR_BOX` on libc++, which matches `typeinfo` by address. `exception_typeinfo` builds a hidden-visibility shared library and fails if its `typeinfo` addresses differ.
