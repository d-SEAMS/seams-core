No OpenMP region in the library lets an exception escape any more. The primitive-ring search and its incremental updater, cage enumeration, affiliation and packing, the cage-topology, prism and fingerprint passes, the neighbour-list and cutoff-graph builders, the C API helpers, the 2D RDF, the shell matcher and the matrix product kernels now hand an exception, such as a failed allocation, to their caller after the region instead of terminating the process. The handler that keeps the first exception no longer takes a lock, and Eigen is built with `EIGEN_DONT_PARALLELIZE`, so it opens no OpenMP region of its own.
