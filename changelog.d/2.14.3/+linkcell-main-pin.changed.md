The linkcell subproject pin moves from the v0.6.0 tag to d-SEAMS/linkcell main. That commit has the CSR single-pass path, the macOS OpenMP search and runtime-path fixes, the Meson sanitize option, which links every consumer with the ThreadSanitizer runtime, and the cargo_profile option, which builds the release Cargo profile in a subproject on every Meson version. The wrap and the offline pre-seeds do not apply an exception-typeinfo patch, because the pinned linkcell carries that fix. The conda OpenMP patch and the macOS runtime-path patch are removed.
