The fingerprint options use the American spelling, and the old names are not accepted. `seams fingerprint --colour-types` is `--color-types`. The Fortran `frame_fingerprint` keyword `colours` is `colors`, and `seams_fingerprint` takes `color_types`. Python `fingerprint(color_types=...)`, Rust `FingerprintOptions::color_types`, and the Lua `colors` field follow the same rename. A key library writes and reads `colors` in its header, so a 2.13 library file with `colours 1` loads without type colors.
