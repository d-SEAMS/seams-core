Type 99 on the mutual frames of the atoms (1, 1, 1) and (2, 1.2, 1.1) on the orthorhombic cell of edge 1e160 with origin (0, 0, 0), and on the triclinic cell of that edge with that origin and tilts 1, 0.5 and -0.25, returns `SEAMS_OK` and an empty list at cutoffs 0.5 and 3.5. Type 99 on that triclinic cell's cutoff graph at cutoff 0.5 returns `SEAMS_OK` and an empty list. When the orthorhombic cutoff graph bins a coordinate, the fraction is (coordinate - origin) times the binary64 reciprocal of the edge. When that fraction is outside [0, 1) it subtracts the floor. A result that is not strictly below 1, NaN included, becomes 0. For a pair the orthorhombic cutoff cell list visits, it keeps the neighbour only when the squared separation of the wrapped coordinates and a periodic cell shift is strictly below the squared cutoff, both computed in binary64. An overflowing square and a NaN square fail that test. Type 0 on (0, 0, 0) and (2e154, 0, 0), edge 1e160, origin (0, 0, 0), cutoff 3e154, returns `SEAMS_OK` and an empty list. `seams_cv_needs_rebuild` compares state only and does not bin the cell, writes stale only on `SEAMS_OK` and leaves it unchanged on any error, and its return list names the range error.
