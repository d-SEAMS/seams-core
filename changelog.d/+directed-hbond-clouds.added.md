Added `seams_system_set_hydrogen_frame` and `seams_directed_hbonds` so a frame can be built from a heavy-atom cloud plus a separate hydrogen cloud, with per-atom types and molecule ids, and so directed donor-hydrogen-acceptor edges can be counted for one donor type set and one acceptor type set. The angle is acceptor-first (0 degrees is linear). The same calls are on the C++ wrapper, `seams_frame_from_hydrogen_cloud`, and `seams_frame_directed_hbonds`.
