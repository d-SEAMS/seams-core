Configure keeps an installed chemfiles only when it has all 37 VMD molfile readers and counts the frame of an AMBER7 restart. An unpatched 0.10.x has three, so configure prints how many it has and which are missing, and builds the patched 0.10.4. The probe is built with the same prefix and compilers as the rest of the build, and a compile failure is reported separately from a crash in the AMBER7 restart, mmCIF or MOL2 read. No build links a chemfiles with fewer readers.
