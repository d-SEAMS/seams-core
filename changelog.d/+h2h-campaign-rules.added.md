The Snakemake rules `h2h_release_build`, `h2h_neighbours`, `h2h_rings`, `h2h_lanes`, `h2h_asv`, `h2h_inventory`, `h2h_summary` and `h2h_campaign` run the head-to-head campaign as one chain, so that nothing else shares the machine, and write a done marker under `bbdir-h2h/<stamp>/`. `snakemake --cores 1 h2h_campaign --config h2h_stamp=<date>` runs it. An interrupted rule resumes its run and skips the samples already recorded. `--config h2h_attempt=-2` adds a suffix to the run ids, raw logs and done markers of `h2h_lanes`, `h2h_asv` and `h2h_inventory`, so that they run again after a failed attempt while the head-to-head rules stay done.
