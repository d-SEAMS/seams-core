Added a stable per-frame hydrogen-bond edge export to the C API (`seams_hbond_edges`) and `libseams_lang` (`seams_frame_hbond_edges`), including deterministic row ordering by `(donor, acceptor, hydrogen)` and optional hydrogen/geometry fields, and added `seams_quenched_analysis`, a callback-driven raw-vs-quenched frame analysis entry point that runs CHILL+, primitive ring counts, and H-bond analysis on callback-returned coordinates, then reports per-frame H-bond edge, ring-count, and classification deltas.
