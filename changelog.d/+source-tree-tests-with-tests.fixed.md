The `source_tree_untracked_*` tests are registered only with `-Dwith_tests=true`, where they now require `git` and `python3` instead of disappearing when either is missing, and `source_tree_untracked_parallel` drives the top-level build directory so it also runs when seams-core is a Meson subproject. The new `with_tests_false_registers_none` test configures the source tree with `-Dwith_tests=false` and fails if any test is registered.
