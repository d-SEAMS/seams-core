The `source_tree_untracked_*` tests are registered only in a top-level build with `-Dwith_tests=true`, where they require `git` and `python3` instead of disappearing when either is missing. They are not registered when seams-core is a Meson subproject. The new `with_tests_false_registers_none` test configures the source tree with `-Dwith_tests=false` and fails if any test is registered.
