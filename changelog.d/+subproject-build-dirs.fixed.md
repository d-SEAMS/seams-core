`option_names`, `tests_do_not_rebuild`, `c_api_installed`, `seams_lang_pkgconfig` and `capi_installed_examples` pass when seams-core is built as a Meson subproject with `-Dwith_tests=true`: their scripts configure, introspect and install the parent's build directory and read `meson-uninstalled` from it, instead of handing Meson seams-core's own build directory, which it refuses. `subproject_build_dirs` configures a scratch consumer project to check this, and `with_tests_false_registers_none` now checks `-Dseams-core:with_tests=false` through the same consumer, using only wraps the build already unpacked.
