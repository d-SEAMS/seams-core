The R package `bindings/r/dseams` builds as a self-contained source package: in a checkout `configure` runs `tools/vendor.sh`, which copies the engine sources and the example dumps into the package, so `R CMD INSTALL bindings/r/dseams` needs no Meson build and `R CMD build` makes a tarball that installs without the checkout. `SEAMS_LIBDIR` and `SEAMS_INCLUDE` link an installed `libseams_lang` instead. `R CMD check --as-cran` leaves only the new-submission NOTE. The Julia package `Dseams` takes its engine from `libseams_jll`, or from the `libseams_lang` that `SEAMS_LANG_LIB` or `Dseams.set_library!` names, and `packaging/yggdrasil/L/libseams` is the Yggdrasil recipe for that JLL. Neither package is on CRAN or in the General registry yet; `bindings/julia/Dseams/dev/develop_jll.jl` develops a stand-in JLL so that Dseams installs from the checkout.
