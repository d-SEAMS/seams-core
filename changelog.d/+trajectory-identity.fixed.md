`TrajectorySequence.unwrap_positions`, `unwrap_centres`, `msd` and `reorientation` match atoms across frames by atom ID and molecules by molecule ID, so a dump that lists atoms in a different order each frame no longer pairs different atoms or molecules between frames. A frame whose atom IDs differ from the first frame's, an atom that changes molecule while molecule IDs are read from the file, or repeated IDs within a frame raise `ValueError`.
