VTF reads a declared atom count of any size that fits in the signed index and in the allocation, including the 201000, 330000 and 1000002 atom structures the 200000 ceiling refused. Extended XYZ keeps every property whose columns are on the atom line, including a 5000-wide SOAP vector, and reports a repeat the line does not carry. TNG XTC2 and XTC3 check every read and write against the packed length, and the Huffman decoder sorts code lengths the way upstream TNG does, so a valid BWLZH or XTC3 frame decodes and a short or unordered table fails cleanly. The run-length, LZ77, move-to-front and Burrows-Wheeler stages return an error instead of reading off their buffers, and the compressor allocates the packed block it measured. A DESRES trajectory opens from its directory or from the empty clickme.dtr inside it once the directory has the timekeys, frame files, metadata and .ddparams the DESRES reader expects; a clickme.dtr outside such a directory is refused and any other empty .dtr file is reported as empty. binpos rejects an atom count the file is too short to hold before allocating it, and a TNG particle array is sized from the decompressed block rather than from a 4096:1 ratio of the file. GAMESS refuses a log whose basis function count is negative or too large for the coefficient table it sizes, instead of allocating from it.
