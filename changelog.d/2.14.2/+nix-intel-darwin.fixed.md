The core Nix flake uses Nixpkgs 26.05 on Intel macOS, selects OVITO and Qt test wheels for each platform, and enables optional engines when Nixpkgs provides them for the target. The legacy Python wrapper in the Nix check uses the bundled Linkcell headers. The Nix build uses patched Chemfiles for trajectory reading and links the LAMMPS plugin against an MPI-enabled LAMMPS build.
