The asv lanes time one serial cold call. `CutoffIce` and `ChillPlusIce` set one OpenMP thread before the library loads, so they no longer time an oversubscribed thread team on one pinned core, which cost about a hundred times the serial call on a thousand molecules. `SEAMS_BENCH_PREWARM=0` drops the warm-up calls the lane setups make. The lanes that run a binary use the release build. An arm without a source, a binary, a frame or an installed tool skips with its reason, where it used to pass without running or fail the sample. `h2h_literature` takes the release library and the running interpreter by default, `CageHeadToHead` has one class per tool so that a missing tool skips only its own arm, and `asv.conf.json` benchmarks `main`.
