The Rust bindings are the crates `dseams-sys` and `dseams` (library names `seams_sys` and `seams`). `dseams-sys` compiles a bundled C API by default and links an installed `libseams` with the `system` feature. The Fortran module is the fpm package `dseams`, usable as a git dependency through the root `fpm.toml`. `bindings/lua/dseams-2.14.0-1.rockspec` builds the LuaRocks rock `dseams` for Lua 5.1 to 5.4 and LuaJIT. `ci_packages.yml` builds and tests all three against an installed `libseams` and checks that their versions follow `meson.build`.
