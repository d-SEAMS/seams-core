The language bindings move to their own repositories: Python to d-SEAMS/PydSEAMSlib (`pydseamslib`, `import dseams` and `import pydseams`), Lua and Fennel to d-SEAMS/yodaStruct (LuaRocks `dseams`), R to d-SEAMS/dseams-r, Julia to d-SEAMS/Dseams.jl, Rust to d-SEAMS/dseams-rs (crates `dseams-sys` and `dseams`), and Fortran to d-SEAMS/dseams-fortran (fpm `dseams`). seams-core builds the engine, the C API `libseams`, the C ABI `libseams_lang`, the `seams` CLI and the engine drivers, and releases conda `libseams` and the Yggdrasil recipe for `libseams_jll`. The Meson options `with_python`, `with_lua`, `fennel_lua`, `with_fortran`, `julia_wrap`, `r_libs_user` and `system_libseams` are removed with the bindings they built. The docs run their Python snippets against the installed `pydseamslib`. `docs/orgmode/development/repositories.org` maps the repositories, the pins and the release order.
