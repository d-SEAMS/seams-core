The language bindings move to their own repositories: Python to d-SEAMS/PydSEAMSlib (`pydseamslib`, `import dseams` and `import pydseams`), Lua and Fennel to d-SEAMS/yodaStruct Git source, R to d-SEAMS/dseams-r, Julia to d-SEAMS/Dseams.jl, Rust to d-SEAMS/dseams-rs (crates `dseams-sys` and `dseams`), and Fortran to the d-SEAMS/dseams-fortran fpm Git dependency. seams-core builds the engine, C API `libseams`, C ABI `libseams_lang`, `seams` CLI and engine drivers, and releases conda `libseams` and the Yggdrasil recipe for `libseams_jll`. Options for in-tree bindings are removed.
