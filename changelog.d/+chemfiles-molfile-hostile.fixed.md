A truncated InsightII MDF, an over-long AMBER7 parm token, a long or hostile VTF record, an AMBER7 restart whose atom count does not fit in the file, and a VMD Tinker file with that kind of count are errors. They used to crash or hang inside the molfile plugin. A header count larger than the file is an error for the other dense molfile readers too. A whitespace-only mmCIF, a LAMMPS Data file with no section, a LAMMPS atom count that does not fit, and an XDR record longer than the file (TPR, TRR, XTC) are errors as well.
