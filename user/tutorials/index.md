# Worked examples {#worked-examples}

A tutorial is a learning path. You finish it with a skill, not a
lookup table.

| tutorial | you learn |
| --- | --- |
| Classify a clathrate | GenIce sI, sII and sH cage census |
| Ice-water interface | CHILL+ slabs along the normal, and the front |
| Nucleation | Largest crystal cluster on three of the 148 frames |
| Brine and NaCl | Ions per layer across the ice front |
| Run in situ | LAMMPS and OpenMM on one cubic cell, skipped when the library is absent |
| Classify ice on the mixed TIP4P example | seams read, CHILL+, cages, and why the scores disagree |
| Ice and clathrate labels | CHILL+ and cage signatures from Python |
| Primitive rings | Franzblau census on one frame |
| Bond-orientational order | q_l and the Lechner-Dellago average |
| Confined water | in-plane RDF, sheet rings, prisms |
| Quasi-one-dimensional ice | where the nanotube and monolayer examples live |
| Paper figures | the supplied numbers behind the 2020 figures |
| Interface slab | Published CHILL+ against the OVITO rule on a slab you build |
| Clathrate cages | GenIce sI, sII and sH |
| Ring statistics | Primitive rings and the shortest-path test |
| Ice in brine | The front, and the crystal count, along a short run |
| Nucleation score | Mean q6bar as a nucleus is restored |
| Science gallery | The full runs, drawn and captioned from their reports |

How-tos solve a goal you already have. Reference names flags and
headers. Explanation covers why CHILL+ and the cage census can disagree.

The paper tutorials provide a short example and the corresponding
full-size result. Each page explains the analysis and the number you should
see.
