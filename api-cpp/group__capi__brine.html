SEAMS_API seams_status seams_brine_analyse ( seams_system * sys,

seams_brine ** out )

Planar ice/brine front from an ice assignment.

ice[i] is non-zero when atom i is ice. water_type 0 keeps every atom whose type is not ion_type. ion_type 0 means the frame has no ions. n_bins 0 selects 20 bins. axis is 0, 1, or 2. The ice fraction cut is 0.5, and the bulk ice and liquid cuts are 0.85 and 0.15.

Parameters
sysFrame handle.
icePer-atom ice flags, length n_ice.
n_iceMust equal the frame count.
water_typeSpecies kept as water, or 0.
ion_typeSpecies kept as ions, or 0 for none.
n_binsBin count along axis, or 0 for 20.
axis0, 1, or 2.
outReceives a new handle. On failure *out is NULL.
Returns
SEAMS_OK, or SEAMS_ERR_NULL, SEAMS_ERR_STATE, SEAMS_ERR_RANGE, SEAMS_ERR_ARG, SEAMS_ERR_NOMEM, SEAMS_ERR_INTERNAL.
Handle access
Non-const only because the call clears the handle's error slot on entry, so seams_handle_error() reports this call. It reads the frame and keeps no scratch on the handle.
Ownership
The caller frees *out with seams_brine_destroy().
Thread safety
Exclusive use of sys.
Example
seams_brine *front = NULL;
if (seams_brine_analyse(sys, ice, n, 1, 2, 0, 2, &front) == SEAMS_OK) {
seams_brine_destroy(front);
}

SEAMS_API seams_status seams_brine_fronts ( const seams_brine * front,
double * z_enter,
double * z_exit,
double * thickness,
int * found )

The two planar crossings of the ice slab.

Lengths are Angstrom, in the frame's cell.

Parameters
frontBrine handle.
z_enterWhere the ice fraction crosses the cut on entering the ice along the positive axis, or NULL.
z_exitThe crossing on leaving the ice, or NULL.
thicknessIce run along the axis, or NULL.
foundReceives 1 when both crossings exist, otherwise 0, or NULL.
Returns
SEAMS_OK, or SEAMS_ERR_NULL when front is NULL or every output pointer is NULL.
Ownership
The caller owns front; the call borrows it. z_enter, z_exit, thickness and found are caller storage that the call fills. The library keeps no pointer to any argument.
Thread safety
Read-only: may run alongside other const calls on front, and not alongside a non-const call on front.
Example
double thick = 0;
int found = 0;
seams_brine_fronts(front, NULL, NULL, &thick, &found);
