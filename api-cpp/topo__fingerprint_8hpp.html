Detailed Description

Label-independent keys for bonded topologies.

A local key names the isomorphism class of the rooted bonded graph within a number of hops of one atom: two atoms share a key exactly when their neighbourhoods are the same graph with the same center, whatever the atom indices. A frame key names the multiset of local keys together with the primitive ring census, so two configurations share a frame key when every atom has a counterpart with the same environment. This is the topological classification k-ART uses to index its event catalog (Trochet, Beland, Joly, Brommer and Mousseau, Phys. Rev. B 91, 224106 (2015)), here on the graphs the ring and cage code already builds.

With nauty linked the local key is the canonical certificate of the rooted graph (the center in its own color cell), an exact invariant. Without it the key is a Weisfeiler-Lehman color refinement hash, which separates every pair of graphs the refinement can distinguish and is what the frame key uses in either build so that keys compare across hosts. The method is recorded on every result.
