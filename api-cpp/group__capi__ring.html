Chordless cycles of one size.

A cycle is chordless when no edge of the graph joins two of its vertices that are not next to each other on the cycle. Every primitive ring is chordless; a chordless cycle need not be primitive. Each cycle is written once as size atom indices: it starts at its lowest index and runs towards the smaller of that atom's two cycle neighbours. Cycles are sorted lexicographically, so the list does not depend on the thread count.

Parameters
nbGraph from seams_neighbours_build().
sizeCycle length, from 3 through 12.
ringsCaller buffer of size times the cycle count ints, or NULL to skip the list.
rings_lenLength of rings in ints. Ignored when rings is NULL.
n_ringsReceives the cycle count. Required when rings is not NULL.
per_atomCaller buffer of one int per atom, or NULL. Receives the number of cycles through each atom.
per_atom_lenLength of per_atom. Ignored when per_atom is NULL.
Returns
SEAMS_OK, or SEAMS_ERR_NULL, SEAMS_ERR_RANGE, SEAMS_ERR_NOMEM, SEAMS_ERR_INTERNAL. rings, n_rings and per_atom may not all be NULL. A short rings buffer returns SEAMS_ERR_RANGE after n_rings and per_atom are written.
Ownership
The caller owns rings and per_atom. Indices are positions in the frame.
Thread safety
Exclusive use of nb.
Example
size_t n_six = 0;
seams_rings_chordless(nb, 6, NULL, 0, &n_six, NULL, 0);

Parameters

typeSpecies filter.
graphSEAMS_GRAPH_CUTOFF or SEAMS_GRAPH_MUTUAL.
max_depthLargest ring size, from 3 through 12.
outReceives a new handle. On failure *out is NULL.
Returns
SEAMS_OK, or SEAMS_ERR_NULL, SEAMS_ERR_STATE, SEAMS_ERR_RANGE, SEAMS_ERR_ARG, SEAMS_ERR_NOMEM, SEAMS_ERR_INTERNAL.
Handle access
Non-const only because the call clears the handle's error slot on entry, so seams_handle_error() reports this call. It reads the frame and keeps no scratch on the handle.
Ownership
The caller frees *out with seams_rings_destroy().
Thread safety
Exclusive use of sys.
Example
seams_rings *rings = NULL;
if (seams_rings_find(sys, 3.5, 0, SEAMS_GRAPH_CUTOFF, 6, &rings) == SEAMS_OK) {
seams_rings_destroy(rings);
}
