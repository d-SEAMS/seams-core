Returns
A positive count. After seams_set_num_threads(0) this is the saved default, which is omp_get_max_threads() when OpenMP is linked and 1 otherwise.

◆ seams_handle_error()

SEAMS_API const char * seams_handle_error ( const void * handle)

Detail string stored on a handle.

Parameters
handleA seams_system, seams_neighbours, seams_rings, seams_cage_set, seams_topo, or seams_brine, or NULL.
Returns
The handle's string, or the thread-local string when handle is NULL. Never NULL.

A call taking the handle non-const clears the string on entry. A call taking it const writes the string only when it fails, so after a successful const call the string still holds the last failure.

Ownership
Owned by the handle. Valid until the next failing call on that handle, the next non-const call on it, or destroy.
Thread safety
Reading a handle requires that no other thread is inside a call on that same handle.
Example
if (seams_chill_plus_n(sys, 3.5, 0, SEAMS_GRAPH_CUTOFF, SEAMS_CHILL_PUBLISHED,
labels, n, NULL) != SEAMS_OK) {
fprintf(stderr, "%s\n", seams_handle_error(sys));
}

SEAMS_API const char * seams_last_error ( void )

Thread-local detail of the last failing call on this thread.

ABI 1 spelling of seams_last_error_message(). Both return the same string.

Returns
Pointer to a thread-local string. Never NULL.
Ownership

◆ seams_set_num_threads()

SEAMS_API seams_status seams_set_num_threads ( int n)

Set the OpenMP team used by later analysis calls.

Parameters
nPositive width, or 0 to restore the width captured at first use. A negative width is rejected.
Returns
SEAMS_OK, or SEAMS_ERR_RANGE when n is negative, SEAMS_ERR_NOMEM, SEAMS_ERR_INTERNAL.
Thread safety
Process-global. Do not call it concurrently with analysis. The stored width is then read by every handle.
Example
seams_set_num_threads(1);
