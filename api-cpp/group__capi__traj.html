SEAMS_API seams_status seams_msd_fit ( const seams_msd * msd,
double t_start,
double t_end,
double * d_total,
double * d_axial,
double * d_lateral,
double * alpha )

Linear Einstein diffusion fit on an MSD accumulator.

Fits MSD_total = 6 D_total t + c, MSD_axial = 2 D_axial t + c, and MSD_lateral = 4 D_lateral t + c over [t_start, t_end]. Pass t_start = 0 and t_end = 0 for the default [0.1 t_max, 0.5 t_max] window.

Parameters
msdMSD handle with at least 2 lag points.
t_startWindow start time, >= 0.
t_endWindow end time, > t_start (or both 0 for default window).
d_totalReceives 3D diffusion coefficient, or NULL.
d_axialReceives 1D axial diffusion coefficient, or NULL.
d_lateralReceives 2D lateral diffusion coefficient, or NULL.
alphaReceives the log-log anomalous exponent, or NULL. Receives NaN when the window holds fewer than two lags with t > 0 and MSD_total > 1e-20, so the log-log fit was skipped; test it with isnan(). The diffusion coefficients are still the linear fit.
Returns
SEAMS_OK when the linear fit succeeded, including a skipped log-log fit (alpha NaN); SEAMS_ERR_NULL; SEAMS_ERR_STATE; SEAMS_ERR_RANGE; SEAMS_ERR_ARG; SEAMS_ERR_NOMEM.
Ownership
Writes scalar outputs owned by the caller.
Thread safety
Read-only on msd.
Example
const double axis[3] = {0, 0, 1};
const double f0[3] = {0, 0, 0}, f1[3] = {0, 0, 1}, f2[3] = {0, 0, 2};
seams_msd *msd = NULL;
double dtot = 0, dax = 0, dlat = 0, alpha = 0;
seams_msd_create(1, 4, 1, 1.0, axis, &msd);
seams_msd_push(msd, f0, 1, NULL, 0);
seams_msd_push(msd, f1, 1, NULL, 0);
seams_msd_push(msd, f2, 1, NULL, 0);
seams_msd_fit(msd, 0.0, 0.0, &dtot, &dax, &dlat, &alpha);
seams_msd_destroy(msd);
