Detailed Description

One frame: coordinates, a cell, and the analyses that read them.

Move-only. The destructor frees the C handle. Methods that read the frame require exclusive use of this object. The Steinhardt scratch inside the library is process-global, so two frames must not run steinhardt, ql, q4q6, or q6bar at the same time. set_num_threads is also process-global.
