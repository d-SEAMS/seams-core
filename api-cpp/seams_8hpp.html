Detailed Description

Idiomatic C++ for the d-SEAMS C API.

One header, no library of its own. It includes seams.h and links libseams. Handles are move-only and free themselves. A status other than success throws seams::Error, and the message is seams_handle_error. Coordinates and cutoffs are Angstrom. A cell is nine LAMMPS numbers: origin, edge lengths, then the tilts xy, xz, yz.

Analyses with several knobs take an options aggregate. Results come back as values, std::vector, or std::string. The caller does not pass output buffers.
