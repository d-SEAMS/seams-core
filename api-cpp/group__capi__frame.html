◆ seams_system_destroy()

SEAMS_API void seams_system_destroy ( seams_system * sys)

Free a frame.

Parameters
sysHandle from seams_system_create(), or NULL. NULL is ignored.
Ownership
The handle and the frame it stored are released. Neighbour, ring, cage, and brine handles built from it stay valid: they hold their own copies.
Thread safety
The caller must not use sys after this returns, and must not call it concurrently with any use of sys.
Example
seams_system_destroy(sys);
sys = NULL;

Read one frame from a trajectory file.

Parameters

pathFilesystem path. CON, LAMMPS dump, and the formats the linked readers accept.
frameFrame index, 1-based, matching the file order.
type_filterNegative keeps every atom. Zero guesses the oxygen species. A positive value keeps that species number.
Returns
SEAMS_OK, or SEAMS_ERR_NULL, SEAMS_ERR_RANGE (frame index or empty frame), SEAMS_ERR_ARG (unreadable file), SEAMS_ERR_NOMEM, SEAMS_ERR_INTERNAL.
Handle access

Ownership
The library copies the frame out of the file.
Thread safety
Exclusive use of sys. Concurrent reads of distinct paths on distinct handles are safe.

SEAMS_API seams_status seams_system_set_atoms ( seams_system * sys,
const double * xyz,
size_t n,
const double * box9,
size_t box_len,
const int * types,
const int * ids )

Store points and a general cell.

Lengths are size_t.

On failure the previously stored frame, if any, is kept.

A reload on the same handle reuses its per-atom storage. When ids is NULL or 1..n and n matches the previous load, the id table is kept as well, so reloading a trajectory frame by frame costs one pass over the input after the finiteness check. seams_system_set_positions() also skips the type and id pass.

Parameters
sysFrame handle.
xyzn times 3 Cartesian coordinates, Angstrom. Every value must be finite.
nAtom count. Zero is rejected. A count that does not fit in the frame's integer width is rejected.
box9Cell numbers: ox, oy, oz, lx, ly, lz, xy, xz, yz.
box_lenMust be 9.
typesAtom types, or NULL to store type 1 for every atom.
idsAtom ids, or NULL to store 1..n. Ids must be unique.
Returns
SEAMS_OK; SEAMS_ERR_NULL for a NULL sys, xyz, or box9; SEAMS_ERR_RANGE for n == 0 or box_len != 9; SEAMS_ERR_BOX for a non-finite cell or a non-positive edge; SEAMS_ERR_ARG for a non-finite coordinate or repeated ids; SEAMS_ERR_NOMEM; SEAMS_ERR_INTERNAL.
Handle access
Non-const: replaces the stored frame. On failure the old frame stays.
Ownership
The library copies the arrays. The caller keeps them.
Thread safety
Exclusive use of sys.
Example
const double xyz[6] = {0, 0, 0, 1.5, 0, 0};
const double box9[9] = {0, 0, 0, 10, 10, 10, 0, 0, 0};
seams_status rc = seams_system_set_atoms(sys, xyz, 2, box9, 9, NULL, NULL);
