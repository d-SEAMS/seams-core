Detailed Description

Preferred spellings for new callers.

Each one reports errors through seams_status and takes a size_t length for every caller buffer.

SEAMS_API seams_status seams_chill_plus_n ( seams_system * sys,
double cutoff,

CHILL+ labels into a buffer of known length.

rule selects the q_lm shell. SEAMS_CHILL_PUBLISHED, the default, is Nguyen and Molinero equation 1: the four closest neighbours. SEAMS_CHILL_OVITO is every neighbour inside the cutoff, which is the OVITO Chill+ modifier. Labels match seams_label.

Parameters
sysFrame handle.
cutoffPositive finite cutoff, Angstrom.
typeSpecies filter. Zero and negative keep every atom.
graphSEAMS_GRAPH_CUTOFF or SEAMS_GRAPH_MUTUAL.
ruleSEAMS_CHILL_PUBLISHED or SEAMS_CHILL_OVITO.
labelsCaller buffer of labels_len ints.
labels_lenMust be at least the frame count.
counts9Nine ints that receive the population of each label, or NULL.
Returns
SEAMS_OK; SEAMS_ERR_NULL for a NULL sys or labels; SEAMS_ERR_STATE when sys holds no frame; SEAMS_ERR_RANGE for a short labels buffer or a non-positive or non-finite cutoff; SEAMS_ERR_ARG for an unknown rule or graph; SEAMS_ERR_NOMEM; SEAMS_ERR_INTERNAL.
Handle access
Non-const: writes each atom's CHILL+ label into the stored frame and clears the handle's error slot on entry. Coordinates, cell, types, and ids are not changed.
Ownership
The caller owns labels and counts9.
Thread safety
Exclusive use of sys.
Example
int counts[9];
seams_chill_plus_n(sys, 3.5, 0, SEAMS_GRAPH_CUTOFF, SEAMS_CHILL_PUBLISHED,
labels, n, counts);

◆ seams_last_error_message()

SEAMS_API const char * seams_last_error_message ( void )

Thread-local detail of the last failing call on this thread.

The string is empty after a successful call on this thread. Prefer seams_handle_error() when the failing call had a handle: that copy survives a later call on another handle. seams_last_error() is the ABI 1 spelling and returns the same string.

Returns
Pointer to a thread-local string. Never NULL.
Ownership
Owned by the library. Valid until the next call on this thread that sets or clears the error.
Thread safety
The storage is thread-local.
Example
seams_status rc = seams_system_natoms(NULL, NULL);
fprintf(stderr, "%s: %s\n", seams_status_string(rc), seams_last_error_message());

Local q4 and q6 on the cutoff shell into buffers of known length.

Parameters
sysFrame handle.
cutoffPositive finite cutoff, Angstrom.
typeSpecies filter.
q4Local q4, or NULL.
q4_lenLength of q4. Ignored when q4 is NULL.
q6Local q6, or NULL. q4 and q6 may not both be NULL.
q6_lenLength of q6. Ignored when q6 is NULL.
Returns
SEAMS_OK, or SEAMS_ERR_NULL, SEAMS_ERR_STATE, SEAMS_ERR_RANGE for a short buffer or a bad cutoff, SEAMS_ERR_NOMEM, SEAMS_ERR_INTERNAL.
Handle access
Non-const only because the call clears the handle's error slot on entry; it reads the frame and nothing else on the handle. The q_lm work arrays belong to the calling thread, so calls on different handles may run at the same time.
Ownership
The caller owns q4 and q6.
Thread safety
Exclusive use of sys. Any q call on another handle may run beside it.
Example
seams_q4q6_n(sys, 3.5, 0, q4, n, q6, n);
