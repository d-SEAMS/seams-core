Detailed Description

Spatial domain decomposition of one periodic frame across ranks.

An orthorhombic frame is cut by linkcell's recursive coordinate bisection of the periodic cell grid. The bound is the tightest a cell-aligned cut can promise. The first call of an analysis weights cells by how many points they hold. Later calls of that analysis weight them by the work measured on the first call. A painted cell only contributes a point that lies within the cutoff of an owned atom. The cut whose heaviest rank load plus thickest ghost fraction is smaller is the one that runs. A skewed frame keeps the slab, pencil, or block cut.
