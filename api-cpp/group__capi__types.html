◆ seams_quench_callback

typedef seams_status(*) seams_quench_callback(const double *xyz, size_t n, const double *box9, size_t box_len, double *xyz_out, size_t xyz_out_len, double *box9_out, size_t box9_out_len, void *user_data)

Callback that returns quenched coordinates for one frame.

The callback receives one frame and writes the quenched coordinates into xyz_out (3 * n doubles) and, optionally, a replacement box into box9_out (nine doubles). Returning SEAMS_OK accepts xyz_out as the quenched frame. Returning an error aborts the quenched analysis call.

Parameters
xyzInput coordinates, 3 * n doubles.
nAtom count.
box9Input cell, nine doubles (ox, oy, oz, lx, ly, lz, xy, xz, yz).
box_lenAlways 9.
xyz_outOutput coordinates, 3 * n doubles.
xyz_out_lenAlways 3 * n.
box9_outOptional output box. May be NULL to keep box9.
box9_out_len9 when box9_out is non-NULL, else 0.
user_dataOpaque caller pointer passed through unchanged.
Returns
SEAMS_OK, or another seams_status to reject this frame.

enum seams_status

Status codes.

Zero is success.

Enumerator
SEAMS_OK 

The call succeeded.

SEAMS_ERR_NULL 

A required pointer is null.

SEAMS_ERR_RANGE 

A number or a buffer length is outside the accepted range, a tilted cell needs a lattice coefficient at or above 2^52 for its minimum image, or the cell is outside what the linked-cell search resolves, such as an edge that needs more bins than linkcell allows.

SEAMS_ERR_BOX 

The cell is missing, non-finite, or has no volume.

SEAMS_ERR_ARG 

A caller argument is the wrong shape, or a coordinate is not finite.

SEAMS_ERR_STATE 

The handle has no frame yet.

SEAMS_ERR_NOMEM 

An allocation failed.

SEAMS_ERR_INTERNAL 

The library hit an internal failure.
