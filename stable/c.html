C#

seams.h is ABI 1 of libseams. A handle is opaque. Coordinates are Angstrom. A cell is nine numbers: ox, oy, oz, lx, ly, lz, xy, xz, yz. A zero tilt is orthorhombic. lx, ly, lz are edge lengths.

docs/examples/minimal_c.c is the short program. docs/examples/c_api_tour.c calls every exported function on the in-tree fixtures. Each capi line below is a line that program prints.

Handle lifecycle#

seams_system_create allocates an empty frame. The caller owns it and passes it to seams_system_destroy. NULL is a valid argument to every destroy function. seams_system_set_atoms stores points and a nine-number cell. Lengths are size_t. seams_system_set_frame is the same store with an int count. seams_system_set_ortho stores an orthorhombic cell. seams_system_read copies one 1-based frame from a trajectory. A negative type filter keeps every atom. A positive filter keeps that species. seams_system_count is the number of points, or 0 for a null handle. Neighbour, ring, cage, brine, and fingerprint handles are separate objects. Destroying the frame does not free them.

One thread uses a handle. Another thread may use a different handle at the same time, including for seams_ql, seams_q4q6, seams_q6bar, and seams_steinhardt: their q_lm scratch belongs to the calling thread. Eight handles can run those calls, and CHILL+, at the same time.

No C API call aborts or exits the process. Every C++ exception is caught inside the library and returned as one of these codes.

Length-checked entry points#

The ABI 1 calls seams_chill_plus, seams_q4q6, and seams_rings_labels write into buffers without a length, and seams_rings_histogram takes an int length. New code calls seams_chill_plus_n, seams_q4q6_n, seams_rings_labels_n, and seams_rings_histogram_n, which take a size_t length for every buffer and return SEAMS_ERR_RANGE when one is short. seams_system_natoms, seams_neighbours_nrows, and seams_rings_nrings return their count through a size_t pointer and report a null or empty handle as a status. The older calls stay exported with the same behavior.

Linking#

libseams is compiled with hidden visibility and a linker export list, so the only exported symbols are the seams_* functions in seams.h. SEAMS_API marks them. The library build defines SEAMS_BUILDING, which selects dllexport on Windows; consumers get dllimport. Define SEAMS_STATIC before including seams.h to link a static archive.

2.13.0 had no libseams. Its C interface was seams_lang.h in libseams_lang. The R and Julia packages still link that library. A function added since 2.13.0 stays compatible. Removing a function or changing a signature is an incompatible change.

seams_last_error and seams_handle_error#

seams_last_error_message and its ABI 1 spelling seams_last_error return the same string. seams_last_error is the detail of the last failing call on this thread. A later successful call on the same thread clears it. The storage is thread-local. seams_handle_error is the copy stored on the handle that failed. A call that takes the handle non-const clears that copy on entry. A call that takes it const writes the copy only when it fails, so a successful const call leaves the last failure in place. The copy stays until the next failing call or non-const call on that handle, or until destroy. Pass NULL and seams_handle_error returns the thread-local string. The caller does not free either pointer.

On an empty frame, seams_chill_plus returns SEAMS_ERR_STATE. The tour prints:

capi seams_last_error system has no frame
capi seams_handle_error no-frame

Const handles#

A function that takes a const handle is a read-only accessor. On success it writes nothing to the handle; on failure it writes only the error copy, under a lock. Several threads may make const calls on one handle at the same time, as long as no non-const call on that handle overlaps them. Read the message with seams_last_error_message when threads share a handle. Eight threads may share one handle this way.

The frame accessors are seams_system_count, seams_system_natoms, seams_system_box, seams_system_positions, seams_system_types, and seams_system_ids. Every query on a neighbour, ring, cage, brine, or fingerprint handle is also const. The ring label cache that seams_rings_labels fills on the first symmetry request is built once, under a lock.

The analyses on a seams_system stay non-const, and each declaration in seams.h says why under “Handle access”:

  • the loads replace the stored frame;

  • seams_chill, seams_chill_plus, and seams_chill_plus_n write CHILL+ labels into the stored frame;

  • the others, including seams_ql, seams_q4q6, seams_q4q6_n, seams_q6bar, and seams_steinhardt, keep no scratch on the handle, and are non-const only because they clear the error copy on entry, which is what lets seams_handle_error report that call. The q_lm scratch of the q calls belongs to the calling thread.

Reloading a frame#

seams_system_set_atoms reuses the storage of the frame it replaces. When the ids are NULL, or 1 to n in order, and the atom count is unchanged, it also keeps the id index. seams_system_set_positions overwrites only the coordinates, and optionally the cell, for a frame of the same atom count; types and ids stay. A trajectory loop calls seams_system_set_atoms once and seams_system_set_positions for each later frame. There is no borrowed-pointer load. Every analysis reads the library’s per-atom records, so a view onto caller memory would be copied on every analysis call instead of once per frame. A failed load or reload leaves the earlier frame in place. seams_system_set_positions keeps that guarantee by checking every coordinate before it writes any, so it reads the input twice and needs no extra memory. The finiteness check scans from the end of the input. seams_system_stage_positions(sys, 1) makes the reload read the input once: it writes into a second set of per-atom records, checks those coordinates in the same pass, and swaps that set in at the end. Call it once after the first seams_system_set_atoms when the second copy of the frame fits.

Threads#

seams_set_num_threads(1) selects one OpenMP thread. seams_set_num_threads(0) restores the library default. A negative width returns SEAMS_ERR_RANGE. seams_get_num_threads reports the width the next call will use. seams_set_num_threads is process-global. Do not call it while another thread is inside seams_get_num_threads.

// Copyright (c) d-SEAMS developers
/* Neighbours: build the 3.5 A list of hexagonal ice and copy it out as CSR.
 * Usage: neighbours <repository root> */
#include "seams.h"

#include <stdio.h>
#include <stdlib.h>

int main(int argc, char **argv) {
  if (argc != 2) {
    fprintf(stderr, "usage: %s <repository root>\n", argv[0]);
    return 2;
  }
  char path[4096];
  snprintf(path, sizeof path, "%s/input/traj/ice1h.lammpstrj", argv[1]);

  int rc = 1;
  seams_system *sys = seams_system_create();
  seams_neighbours *nb = NULL;
  int *offsets = NULL;
  int *cols = NULL;
  if (sys == NULL || seams_system_read(sys, path, 1, 1) != SEAMS_OK) {
    fprintf(stderr, "read: %s\n", seams_last_error());
    goto done;
  }
  if (seams_neighbours_build(sys, 3.5, 1, SEAMS_GRAPH_CUTOFF, &nb) != SEAMS_OK) {
    fprintf(stderr, "neighbours: %s\n", seams_handle_error(sys));
    goto done;
  }
  /* Query the lengths, then copy into caller buffers. */
  size_t n_offsets = 0;
  size_t nnz = 0;
  if (seams_neighbours_copy(nb, NULL, 0, &n_offsets, NULL, 0, &nnz) != SEAMS_OK) {
    goto done;
  }
  offsets = malloc(n_offsets * sizeof *offsets);
  cols = malloc((nnz > 0 ? nnz : 1) * sizeof *cols);
  if (offsets == NULL || cols == NULL ||
      seams_neighbours_copy(nb, offsets, n_offsets, &n_offsets, cols, nnz, &nnz) != SEAMS_OK) {
    goto done;
  }
  /* Every oxygen of hexagonal ice has four neighbours. */
  for (size_t i = 0; i + 1 < n_offsets; i++) {
    if (offsets[i + 1] - offsets[i] != 4) {
      fprintf(stderr, "row %zu has %d neighbours\n", i, offsets[i + 1] - offsets[i]);
      goto done;
    }
  }
  printf("neighbours rows %zu pairs %zu\n", n_offsets - 1, nnz);
  rc = 0;

done:
  free(cols);
  free(offsets);
  seams_neighbours_destroy(nb);
  seams_system_destroy(sys);
  return rc;
}

/* Errors: status codes, the thread-local message and the copy kept on the
 * handle that failed.
 * Usage: errors */
#include "seams.h"

#include <stdio.h>
#include <string.h>

int main(void) {
  int rc = 1;
  seams_system *sys = seams_system_create();
  seams_neighbours *nb = NULL;
  if (sys == NULL) {
    return 1;
  }
  /* A system with no frame cannot build neighbours. */
  seams_status status = seams_neighbours_build(sys, 3.5, 0, SEAMS_GRAPH_CUTOFF, &nb);
  if (status != SEAMS_ERR_STATE || nb != NULL) {
    fprintf(stderr, "expected SEAMS_ERR_STATE, got %d\n", (int)status);
    goto done;
  }
  /* The code's fixed text, the detail for this thread, and the handle's copy. */
  const char *text = seams_status_string(status);
  const char *thread_detail = seams_last_error();
  const char *handle_detail = seams_handle_error(sys);
  if (text[0] == '\0' || thread_detail[0] == '\0' || handle_detail[0] == '\0' ||
      strcmp(seams_status_string(SEAMS_OK), text) == 0) {
    fprintf(stderr, "messages: '%s' '%s' '%s'\n", text, thread_detail, handle_detail);
    goto done;
  }
  printf("error %s: %s\n", text, handle_detail);
  rc = 0;

done:
  seams_system_destroy(sys);
  return rc;
}

What the tour runs#

The eight-atom cell is the diamond in docs/examples/ice.c. Every atom is cubic. input/traj/ice1h.lammpstrj is the 128-oxygen ice Ih cell. input/traj/genice_sI.lammpstrj is the 46-oxygen sI cage. input/traj/exampleTraj.lammpstrj is the mixed TIP4P dump used for hydrogen bonds, sites, and domains. The cutoff is 3.5 angstroms unless a line below says otherwise.

docs/examples/core_counts.c reads input/traj/ice1h.lammpstrj and input/traj/genice_sII.lammpstrj and checks the C core: 128 hexagonal waters and 256 six-rings, then 136 clathrate waters, 144 five-rings and 16 six-rings. It prints hexagonal 128, rings6 256, clathrate 136 and rings5 144, and returns 0.

// Copyright (c) d-SEAMS developers
/* Ice Ih and sII counts from the C core.
 *
 * input/traj/ice1h.lammpstrj: 128 waters, all hexagonal, 256 six-rings.
 * input/traj/genice_sII.lammpstrj: 136 waters, all clathrate, 144 five-rings
 * and 16 six-rings. seams_chill_plus and seams_rings_histogram at 3.5 Å.
 */
#include "seams.h"
#include "seams_lammps_box.h"

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

static int read_dump(const char *path, double **xyz, int **types, int *n, double box9[9]) {
  FILE *in = fopen(path, "r");
  char line[512];
  int reading = 0;
  int cap = 0;
  if (in == NULL) {
    return 1;
  }
  *n = 0;
  *xyz = NULL;
  *types = NULL;
  while (fgets(line, sizeof line, in) != NULL) {
    if (strncmp(line, "ITEM: BOX BOUNDS", 16) == 0) {
      double bound_lo[3], bound_hi[3], tilt[3];
      int axis;
      for (axis = 0; axis < 3; ++axis) {
        char bound[128];
        if (fgets(bound, sizeof bound, in) == NULL) {
          fclose(in);
          return 1;
        }
        tilt[axis] = 0.0;
        if (sscanf(bound, "%lf %lf %lf", &bound_lo[axis], &bound_hi[axis], &tilt[axis]) < 2) {
          fclose(in);
          return 1;
        }
      }
      seams_lammps_bounds(bound_lo, bound_hi, tilt, box9);
    } else if (strncmp(line, "ITEM: ATOMS", 11) == 0) {
      reading = 1;
    } else if (reading) {
      int id, kind;
      double x, y, z;
      if (sscanf(line, "%d %d %lf %lf %lf", &id, &kind, &x, &y, &z) != 5) {
        break;
      }
      if (*n >= cap) {
        cap = cap == 0 ? 64 : cap * 2;
        *xyz = realloc(*xyz, (size_t)cap * 3 * sizeof(double));
        *types = realloc(*types, (size_t)cap * sizeof(int));
        if (*xyz == NULL || *types == NULL) {
          fclose(in);
          return 1;
        }
      }
      (*types)[*n] = kind;
      (*xyz)[3 * *n] = x;
      (*xyz)[3 * *n + 1] = y;
      (*xyz)[3 * *n + 2] = z;
      *n += 1;
    }
  }
  fclose(in);
  return *n == 0;
}

static int classify(const char *path, int *n_out, int counts[9], int rings[13]) {
  double *xyz = NULL;
  int *types = NULL;
  int n = 0;
  double box9[9];
  seams_system *sys;
  seams_rings *found = NULL;
  int *labels;
  if (read_dump(path, &xyz, &types, &n, box9) != 0) {
    return 1;
  }
  labels = calloc((size_t)n, sizeof(int));
  sys = seams_system_create();
  if (labels == NULL || sys == NULL ||
      seams_system_set_frame(sys, xyz, n, box9, types, NULL) != SEAMS_OK ||
      seams_chill_plus(sys, 3.5, 0, SEAMS_GRAPH_CUTOFF, SEAMS_CHILL_PUBLISHED, labels,
                       counts) != SEAMS_OK ||
      seams_rings_find(sys, 3.5, 0, SEAMS_GRAPH_CUTOFF, 6, &found) != SEAMS_OK ||
      seams_rings_histogram(found, rings, 13) != SEAMS_OK) {
    free(labels);
    free(xyz);
    free(types);
    if (found != NULL) {
      seams_rings_destroy(found);
    }
    if (sys != NULL) {
      seams_system_destroy(sys);
    }
    return 1;
  }
  *n_out = n;
  seams_rings_destroy(found);
  seams_system_destroy(sys);
  free(labels);
  free(xyz);
  free(types);
  return 0;
}

int main(void) {
  int n = 0;
  int counts[9] = {0};
  int rings[13] = {0};
  if (seams_set_num_threads(1) != SEAMS_OK) {
    return 1;
  }
  if (classify("input/traj/ice1h.lammpstrj", &n, counts, rings) != 0 || n != 128 ||
      counts[1] != 128 || rings[6] != 256) {
    fprintf(stderr, "ice Ih n=%d hexagonal=%d rings6=%d\n", n, counts[1], rings[6]);
    return 1;
  }
  printf("hexagonal 128\n");
  printf("rings6 256\n");
  if (classify("input/traj/genice_sII.lammpstrj", &n, counts, rings) != 0 || n != 136 ||
      counts[4] != 136 || rings[5] != 144 || rings[6] != 16) {
    fprintf(stderr, "sII n=%d clathrate=%d rings5=%d rings6=%d\n", n, counts[4], rings[5],
            rings[6]);
    return 1;
  }
  printf("clathrate 136\n");
  printf("rings5 144\n");
  return 0;
}

Purpose: Directed hydrogen-bond edges for selected donor and acceptor types.

Each edge is one accepting hydrogen. Rows are sorted by donor, then hydrogen, then acceptor, as frame indices. The angle is acceptor-first. The donor-acceptor vector is the minimum image of acceptor minus donor. The acceptor-hydrogen vector is the minimum image of acceptor minus the hydrogen. A linear donor-hydrogen-acceptor geometry has angle 0 degrees. The acceptor-hydrogen distance is kept only when it is strictly below dist_cutoff. The angle is kept when it is less than or equal to angle_cutoff. The pair list keeps a donor and acceptor only when their minimum image is strictly below pair_cutoff, on an orthorhombic or triclinic cell. For a triclinic cell, every face separation must be at least twice pair_cutoff; a thinner cell can miss valid pairs. Each hydrogen is assigned to the nearest heavy atom that shares its molID, then kept only when that atom’s type is in donor_types. The lower index wins a distance tie. exclude_same_mol of 1 drops a pair that shares a molID. An empty donor set or acceptor set writes zero edges. seams_msd_fit#

Purpose: Linear Einstein diffusion fit on an MSD accumulator.

Fits MSD_total = 6 D_total t + c, MSD_axial = 2 D_axial t + c, and MSD_lateral = 4 D_lateral t + c over [t_start, t_end]. Pass t_start = 0 and t_end = 0 for the default [0.1 t_max, 0.5 t_max] window.

seams_status seams_msd_fit(const seams_msd *msd, double t_start, double t_end, double *d_total, double *d_axial, double *d_lateral, double *alpha);

Parameters: msd, t_start, t_end, d_total, d_axial, d_lateral, alpha.

  • msd: MSD handle with at least 2 lag points.

  • t_start: Window start time, >= 0.

  • t_end: Window end time, > t_start (or both 0 for default window).

  • d_total: Receives 3D diffusion coefficient, or NULL.

  • d_axial: Receives 1D axial diffusion coefficient, or NULL.

  • d_lateral: Receives 2D lateral diffusion coefficient, or NULL.

  • alpha: Receives the log-log anomalous exponent, or NULL. Receives NaN when the window holds fewer than two lags with t > 0 and MSD_total > 1e-20, so the log-log fit was skipped; test it with isnan(). The diffusion coefficients are still the linear fit.

Returns: SEAMS_OK when the linear fit succeeded, including a skipped log-log fit (alpha NaN); SEAMS_ERR_NULL; SEAMS_ERR_STATE; SEAMS_ERR_RANGE; SEAMS_ERR_ARG; SEAMS_ERR_NOMEM.

seams_tetrahedral_order#

Purpose: Errington-Debenedetti tetrahedral order for arbitrary selections.

centres and partners contain zero-based frame indices. A NULL pointer with zero length selects every atom. static double mean_of(const double *values, int n) {
  double sum = 0.0;

static void diamond8(double *xyz, double *edge) {
  const double a = 2.75 * 4.0 / sqrt(3.0);
  const double fcc[4][3] = {{0, 0, 0}, {0.5, 0.5, 0}, {0.5, 0, 0.5}, {0, 0.5, 0.5}};
  const double basis[2][3] = {{0, 0, 0}, {0.25, 0.25, 0.25}};
  int n = 0;
  for (int f = 0; f < 4; ++f) {
    for (int s = 0; s < 2; ++s, ++n) {
      xyz[3 * n] = (fcc[f][0] + basis[s][0]) * a;
      xyz[3 * n + 1] = (fcc[f][1] + basis[s][1]) * a;
      xyz[3 * n + 2] = (fcc[f][2] + basis[s][2]) * a;
    }
  }
  *edge = a;
}

       mix);
  printf("capi seams_site_table %d\n", count_label(kinds, seams_system_count(mix), SEAMS_SITE_WATER_O));

  const size_t mix_n = (size_t)seams_system_count(mix);
  int *mix_mols = calloc(mix_n, sizeof(int));
  need("mols", seams_mols(mix, mix_mols, mix_n), mix);
  printf("capi seams_mols %zu\n", mix_n);
  need("setmols", seams_set_mols(mix, mix_mols, mix_n), mix);
  printf("capi seams_set_mols %zu\n", mix_n);

  size_t nmols = 0;
  need("mcentq", seams_molecule_centres(mix, NULL, 0, NULL, 0, NULL, NULL, 0, &nmols), mix);
  printf("capi seams_molecule_centres %zu\n", nmols);

  seams_reorient *rot = NULL;

  seams_reorient_destroy(rot);
  printf("capi seams_reorient_destroy ok\n");

  free(mix_mols);
  free(wbis);

  seams_rings_destroy(rings);
  seams_neighbours_destroy(nb);
  seams_neighbours_destroy(knn);
