C¶

seams.h is ABI 1 of libseams. A handle is opaque. Coordinates are Angstrom. A cell is nine numbers: ox, oy, oz, lx, ly, lz, xy, xz, yz. A zero tilt is orthorhombic. lx, ly, lz are edge lengths.

docs/examples/minimal_c.c is the short program. docs/examples/c_api_tour.c calls every exported function on the in-tree fixtures. meson test docs_c_api_tour compiles that file, runs it, and requires each printed capi line below to match the run.

Handle lifecycle¶

seams_system_create allocates an empty frame. The caller owns it and passes it to seams_system_destroy. NULL is a valid argument to every destroy function. seams_system_set_atoms stores points and a nine-number cell. Lengths are size_t. seams_system_set_frame is the same store with an int count. seams_system_set_ortho stores an orthorhombic cell. seams_system_read copies one 1-based frame from a trajectory. A negative type filter keeps every atom. A positive filter keeps that species. seams_system_count is the number of points, or 0 for a null handle. Neighbour, ring, cage, brine, and fingerprint handles are separate objects. Destroying the frame does not free them.

One thread uses a handle. Another thread may use a different handle at the same time, including for seams_ql, seams_q4q6, seams_q6bar, and seams_steinhardt: their q_lm scratch belongs to the calling thread. tests/capi_q_threads.c runs them, and CHILL+, on eight handles in eight threads.

Status codes¶

Length-checked entry points¶

The ABI 1 calls seams_chill_plus, seams_q4q6, and seams_rings_labels write into buffers without a length, and seams_rings_histogram takes an int length. New code calls seams_chill_plus_n, seams_q4q6_n, seams_rings_labels_n, and seams_rings_histogram_n, which take a size_t length for every buffer and return SEAMS_ERR_RANGE when one is short. seams_system_natoms, seams_neighbours_nrows, and seams_rings_nrings return their count through a size_t pointer and report a null or empty handle as a status. The older calls stay exported with the same behavior.

Linking¶

libseams is compiled with hidden visibility and a linker export list, so the only exported symbols are the seams_* functions in seams.h. SEAMS_API marks them. The library build defines SEAMS_BUILDING, which selects dllexport on Windows; consumers get dllimport. Define SEAMS_STATIC before including seams.h to link a static archive. tests/capi_symbols.txt is the exported list, and the capi_symbols test compares it with the header and the built library. capi_abi compares the exported names with scripts/abi_baseline.txt. When libabigail’s abidiff is on PATH at configure time, it also builds libseams once more with debug info and compares its types with the ABI 1 corpus in scripts/abi_baseline.abi: added functions pass, and anything else fails. The abi pixi environment carries conda-forge’s libabigail, so pixi run -e abi meson setup <builddir> finds it, and the capi-abi CI job runs that way. Distribution packages work too: abigail-tools on Debian and Ubuntu, libabigail on Fedora. The corpus is format 2.4, which libabigail 2.9 and 3.0 read. Without abidiff, or with an older one, capi_abi still checks the exported names, says the type step was skipped, and passes.

The 2.13.0 release had no libseams. Its C interface was seams_lang.h in libseams_lang, which the R and Julia packages still use. capi_abi_2_13 builds libseams_lang with debug info and compares its seams_* functions with the 2.13.0 corpus in scripts/abi_2.13.0_seams_lang.abi. Functions added since 2.13.0 pass, and a removed function or a changed signature fails. capi_abi_2_13_selftest edits copies of the corpus to prove the comparison catches both. Without abidiff, both tests are skipped.

seams_last_error and seams_handle_error¶

seams_last_error_message and its ABI 1 spelling seams_last_error return the same string. seams_last_error is the detail of the last failing call on this thread. A later successful call on the same thread clears it. The storage is thread-local. seams_handle_error is the copy stored on the handle that failed. A call that takes the handle non-const clears that copy on entry. A call that takes it const writes the copy only when it fails, so a successful const call leaves the last failure in place. The copy stays until the next failing call or non-const call on that handle, or until destroy. Pass NULL and seams_handle_error returns the thread-local string. The caller does not free either pointer.

On an empty frame, seams_chill_plus returns SEAMS_ERR_STATE. The tour prints:

capi seams_last_error system has no frame
capi seams_handle_error no-frame

Const handles¶

A function that takes a const handle is a read-only accessor. On success it writes nothing to the handle; on failure it writes only the error copy, under a lock. Several threads may make const calls on one handle at the same time, as long as no non-const call on that handle overlaps them. Read the message with seams_last_error_message when threads share a handle. tests/capi_const_threads.c runs eight threads this way.

The frame accessors are seams_system_count, seams_system_natoms, seams_system_box, seams_system_positions, seams_system_types, and seams_system_ids. Every query on a neighbour, ring, cage, brine, or fingerprint handle is also const. The ring label cache that seams_rings_labels fills on the first symmetry request is built once, under a lock.

The analyses on a seams_system stay non-const, and each declaration in seams.h says why under “Handle access”:

  • the loads replace the stored frame;

  • seams_chill, seams_chill_plus, and seams_chill_plus_n write CHILL+ labels into the stored frame;

  • the others, including seams_ql, seams_q4q6, seams_q4q6_n, seams_q6bar, and seams_steinhardt, keep no scratch on the handle, and are non-const only because they clear the error copy on entry, which is what lets seams_handle_error report that call. The q_lm scratch of the q calls belongs to the calling thread.

Reloading a frame¶

seams_system_set_atoms reuses the storage of the frame it replaces. When the ids are NULL, or 1 to n in order, and the atom count is unchanged, it also keeps the id index. seams_system_set_positions overwrites only the coordinates, and optionally the cell, for a frame of the same atom count; types and ids stay. A trajectory loop calls seams_system_set_atoms once and seams_system_set_positions for each later frame. There is no borrowed-pointer load. Every analysis reads the library’s per-atom records, so a view onto caller memory would be copied on every analysis call instead of once per frame. A failed load or reload leaves the earlier frame in place. seams_system_set_positions keeps that guarantee by checking every coordinate before it writes any, so it reads the input twice and needs no extra memory. The check scans from the end of the input, so the write pass finds its start still in cache. In a trajectory loop a reload then costs 2 to 5% more than writing the coordinates into the C++ frame directly at 4096 and 110592 molecules, and about 12% more at 884736, where the second read of the 21 MB input comes from L3. seams_system_stage_positions(sys, 1) makes it read the input once instead: it writes into a second set of per-atom records, checked in the same pass, and swaps that set in at the end. That reload stays within 5% of the direct write at each of those sizes. The set costs about 72 bytes per atom, 15 to 18% of the resident memory of a process that has loaded an ice frame of 0.1 to 0.9 million molecules and run CHILL+ on it.

For large frames staged mode is the zero-overhead path. Once the input no longer fits in L2, the default check costs a full second read of it, and staging is the only way to read it once. Threads¶

seams_set_num_threads(1) selects one OpenMP thread. seams_set_num_threads(0) restores the library default. // Copyright (c) d-SEAMS developers
/* Neighbours: build the 3.5 A list of hexagonal ice and copy it out as CSR.
 * Usage: neighbours <repository root> */
#include "seams.h"

#include <stdio.h>
#include <stdlib.h>

int main(int argc, char **argv) {
  if (argc != 2) {
    fprintf(stderr, "usage: %s <repository root>\n", argv[0]);
    return 2;
  }
  char path[4096];
  snprintf(path, sizeof path, "%s/input/traj/ice1h.lammpstrj", argv[1]);

  int rc = 1;
  seams_system *sys = seams_system_create();
  seams_neighbours *nb = NULL;
  int *offsets = NULL;
  int *cols = NULL;
  if (sys == NULL || seams_system_read(sys, path, 1, 1) != SEAMS_OK) {
    fprintf(stderr, "read: %s\n", seams_last_error());
    goto done;
  }
  if (seams_neighbours_build(sys, 3.5, 1, SEAMS_GRAPH_CUTOFF, &nb) != SEAMS_OK) {
    fprintf(stderr, "neighbours: %s\n", seams_handle_error(sys));
    goto done;
  }
  /* Query the lengths, then copy into caller buffers. */
  size_t n_offsets = 0;
  size_t nnz = 0;
  if (seams_neighbours_copy(nb, NULL, 0, &n_offsets, NULL, 0, &nnz) != SEAMS_OK) {
    goto done;
  }
  offsets = malloc(n_offsets * sizeof *offsets);
  cols = malloc((nnz > 0 ? nnz : 1) * sizeof *cols);
  if (offsets == NULL || cols == NULL ||
      seams_neighbours_copy(nb, offsets, n_offsets, &n_offsets, cols, nnz, &nnz) != SEAMS_OK) {
    goto done;
  }
  /* Every oxygen of hexagonal ice has four neighbours. */
  for (size_t i = 0; i + 1 < n_offsets; i++) {
    if (offsets[i + 1] - offsets[i] != 4) {
      fprintf(stderr, "row %zu has %d neighbours\n", i, offsets[i + 1] - offsets[i]);
      goto done;
    }
  }
  printf("neighbours rows %zu pairs %zu\n", n_offsets - 1, nnz);
  rc = 0;

done:
  free(cols);
  free(offsets);
  seams_neighbours_destroy(nb);
  seams_system_destroy(sys);
  return rc;
}

// Copyright (c) d-SEAMS developers
/* Ice Ih and sII counts from the C core.
 *
 * input/traj/ice1h.lammpstrj: 128 waters, all hexagonal, 256 six-rings.
 * input/traj/genice_sII.lammpstrj: 136 waters, all clathrate, 144 five-rings
 * and 16 six-rings. seams_chill_plus and seams_rings_histogram at 3.5 Å.
 */
#include "seams.h"
#include "seams_lammps_box.h"

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

static int read_dump(const char *path, double **xyz, int **types, int *n, double box9[9]) {
  FILE *in = fopen(path, "r");
  char line[512];
  int reading = 0;
  int cap = 0;
  if (in == NULL) {
    return 1;
  }
  *n = 0;
  *xyz = NULL;
  *types = NULL;
  while (fgets(line, sizeof line, in) != NULL) {
    if (strncmp(line, "ITEM: BOX BOUNDS", 16) == 0) {
      double bound_lo[3], bound_hi[3], tilt[3];
      int axis;
      for (axis = 0; axis < 3; ++axis) {
        char bound[128];
        if (fgets(bound, sizeof bound, in) == NULL) {
          fclose(in);
          return 1;
        }
        tilt[axis] = 0.0;
        if (sscanf(bound, "%lf %lf %lf", &bound_lo[axis], &bound_hi[axis], &tilt[axis]) < 2) {
          fclose(in);
          return 1;
        }
      }
      seams_lammps_bounds(bound_lo, bound_hi, tilt, box9);
    } else if (strncmp(line, "ITEM: ATOMS", 11) == 0) {
      reading = 1;
    } else if (reading) {
      int id, kind;
      double x, y, z;
      if (sscanf(line, "%d %d %lf %lf %lf", &id, &kind, &x, &y, &z) != 5) {
        break;
      }
      if (*n >= cap) {
        cap = cap == 0 ? 64 : cap * 2;
        *xyz = realloc(*xyz, (size_t)cap * 3 * sizeof(double));
        *types = realloc(*types, (size_t)cap * sizeof(int));
        if (*xyz == NULL || *types == NULL) {
          fclose(in);
          return 1;
        }
      }
      (*types)[*n] = kind;
      (*xyz)[3 * *n] = x;
      (*xyz)[3 * *n + 1] = y;
      (*xyz)[3 * *n + 2] = z;
      *n += 1;
    }
  }
  fclose(in);
  return *n == 0;
}

static int classify(const char *path, int *n_out, int counts[9], int rings[13]) {
  double *xyz = NULL;
  int *types = NULL;
  int n = 0;
  double box9[9];
  seams_system *sys;
  seams_rings *found = NULL;
  int *labels;
  if (read_dump(path, &xyz, &types, &n, box9) != 0) {
    return 1;
  }
  labels = calloc((size_t)n, sizeof(int));
  sys = seams_system_create();
  if (labels == NULL || sys == NULL ||
      seams_system_set_frame(sys, xyz, n, box9, types, NULL) != SEAMS_OK ||
      seams_chill_plus(sys, 3.5, 0, SEAMS_GRAPH_CUTOFF, SEAMS_CHILL_PUBLISHED, labels,
                       counts) != SEAMS_OK ||
      seams_rings_find(sys, 3.5, 0, SEAMS_GRAPH_CUTOFF, 6, &found) != SEAMS_OK ||
      seams_rings_histogram(found, rings, 13) != SEAMS_OK) {
    free(labels);
    free(xyz);
    free(types);
    if (found != NULL) {
      seams_rings_destroy(found);
    }
    if (sys != NULL) {
      seams_system_destroy(sys);
    }
    return 1;
  }
  *n_out = n;
  seams_rings_destroy(found);
  seams_system_destroy(sys);
  free(labels);
  free(xyz);
  free(types);
  return 0;
}

int main(void) {
  int n = 0;
  int counts[9] = {0};
  int rings[13] = {0};
  if (seams_set_num_threads(1) != SEAMS_OK) {
    return 1;
  }

static double mean_of(const double *values, int n) {
  double sum = 0.0;
  for (int i = 0; i < n; ++i) {

  }

static void diamond8(double *xyz, double *edge) {
  const double a = 2.75 * 4.0 / sqrt(3.0);
  const double fcc[4][3] = {{0, 0, 0}, {0.5, 0.5, 0}, {0.5, 0, 0.5}, {0, 0.5, 0.5}};
  const double basis[2][3] = {{0, 0, 0}, {0.25, 0.25, 0.25}};
  int n = 0;
  for (int f = 0; f < 4; ++f) {
    for (int s = 0; s < 2; ++s, ++n) {
      xyz[3 * n] = (fcc[f][0] + basis[s][0]) * a;
      xyz[3 * n + 1] = (fcc[f][1] + basis[s][1]) * a;
      xyz[3 * n + 2] = (fcc[f][2] + basis[s][2]) * a;
    }
  }
  *edge = a;
}
