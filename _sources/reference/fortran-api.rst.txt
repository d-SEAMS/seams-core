Fortran
=======

FORD-style comments (``!>``) and the public type-bound procedures in `dseams-fortran <https://github.com/d-SEAMS/dseams-fortran>`_. ``seams_c`` is the ``bind(C)`` layer. ``seams`` is the module a program uses.
