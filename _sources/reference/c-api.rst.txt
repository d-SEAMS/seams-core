C
=

``include/seams.h`` is the native C API and the ABI the other languages call. The pages under :doc:`/capi/index` group the same declarations. This page lists every ``SEAMS_API`` function the header declares, with the signature and the parameter notes from that header.

The C column is the function itself: this is the C API.

Native API
----------

Generated from the sources named below. A name on this page is a public call in that language.

seams_brine_analyse
~~~~~~~~~~~~~~~~~~~

.. api-symbol: seams_brine_analyse

.. code-block:: c

   seams_status seams_brine_analyse(seams_system *sys, const int *ice, size_t n_ice, int water_type, int ion_type, int n_bins, int axis, seams_brine **out)

Planar ice/brine front from an ice assignment.

Parameters

- **sys**: Frame handle.
- **ice**: Per-atom ice flags, length n\_ice.
- **n\_ice**: Must equal the frame count.
- **water\_type**: Species kept as water, or 0.
- **ion\_type**: Species kept as ions, or 0 for none.
- **n\_bins**: Bin count along axis, or 0 for 20.
- **axis**: 0, 1, or 2.
- **out**: Receives a new handle. On failure \*out is NULL.

Returns

::SEAMS\_OK, or ::SEAMS\_ERR\_NULL, ::SEAMS\_ERR\_STATE, ::SEAMS\_ERR\_RANGE, ::SEAMS\_ERR\_ARG, ::SEAMS\_ERR\_NOMEM, ::SEAMS\_ERR\_INTERNAL.

.. code-block:: c

   seams_status seams_brine_fronts(const seams_brine *front, double *z_enter, double *z_exit, double *thickness, int *found)

The two planar crossings of the ice slab.

Parameters

- **front**: Brine handle.

   seams_status seams_density_fractional(seams_system *sys, int type, int bins, int axis, const double *direction, size_t direction_len, double origin, const double *masses, size_t masses_len, double *coordinate, double *number_density, double *mass_density, double *bin_volume, size_t cap, size_t *n_out)

Number and mass density along a cell axis or a Cartesian direction.

Parameters

- **sys**: Frame handle.

- **mass\_density**: Mass density in the caller's mass units per cubic Angstrom, or NULL to skip. An amu mass gives amu per cubic Angstrom; times 1.66054 that is grams per cubic centimetre.
- **bin\_volume**: Bin volume in cubic Angstrom, or NULL to skip.
- **cap**: Capacity of each non-NULL column.
- **n\_out**: Receives the bin count.

Returns

::SEAMS\_OK, or ::SEAMS\_ERR\_NULL, ::SEAMS\_ERR\_STATE, ::SEAMS\_ERR\_RANGE, ::SEAMS\_ERR\_BOX, ::SEAMS\_ERR\_ARG, ::SEAMS\_ERR\_NOMEM, ::SEAMS\_ERR\_INTERNAL.

Create a streaming H-bond lifetime accumulator from per-frame edges.

Parameters

- **max\_lag**: Maximum lag in frames, or 0 to retain all lags. Above PTRDIFF\_MAX / sizeof(double) - 1 the lag bins cannot be allocated, which is ::SEAMS\_ERR\_RANGE.

- **directed**: Non-zero treats (donor, acceptor) as directed; zero canonicalizes pairs.
