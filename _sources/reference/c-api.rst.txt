C
=

``include/seams.h`` is the native C API and the ABI the other languages call. The pages under :doc:`/capi/index` group the same declarations. This page lists every ``SEAMS_API`` function the header declares, with the signature and the parameter notes from that header.

The C column is the function itself: this is the C API.

Native API
----------

Generated from the sources named below. A name on this page is a public call in that language.

seams_brine_analyse
~~~~~~~~~~~~~~~~~~~

.. api-symbol: seams_brine_analyse

.. code-block:: c

   seams_status seams_brine_analyse(seams_system *sys, const int *ice, size_t n_ice, int water_type, int ion_type, int n_bins, int axis, seams_brine **out)

Planar ice/brine front from an ice assignment.

Parameters

- **sys**: Frame handle.
- **ice**: Per-atom ice flags, length n\_ice.
- **n\_ice**: Must equal the frame count.
- **water\_type**: Species kept as water, or 0.
- **ion\_type**: Species kept as ions, or 0 for none.
- **n\_bins**: Bin count along axis, or 0 for 20.
- **axis**: 0, 1, or 2.
- **out**: Receives a new handle. On failure \*out is NULL.

Returns

::SEAMS\_OK, or ::SEAMS\_ERR\_NULL, ::SEAMS\_ERR\_STATE, ::SEAMS\_ERR\_RANGE, ::SEAMS\_ERR\_ARG, ::SEAMS\_ERR\_NOMEM, ::SEAMS\_ERR\_INTERNAL.

seams_brine_fronts

.. code-block:: c

   seams_status seams_brine_fronts(const seams_brine *front, double *z_enter, double *z_exit, double *thickness, int *found)

The two planar crossings of the ice slab.

Parameters

- **front**: Brine handle.
- **z\_enter**: Where the ice fraction crosses the cut on entering the ice along the positive axis, or NULL.
- **z\_exit**: The crossing on leaving the ice, or NULL.
- **thickness**: Ice run along the axis, or NULL.
- **found**: Receives 1 when both crossings exist, otherwise 0, or NULL.

Returns

::SEAMS\_OK, or ::SEAMS\_ERR\_NULL when front is NULL or every output pointer is NULL.

   seams_status seams_cages(seams_system *sys, double cutoff, int type, int graph, int k, int complete, seams_cage_set **out)

Hexagonal and double-diamond cages. Same search as seams\_cages\_find().

Parameters

   seams_status seams_cages_find(seams_system *sys, double cutoff, int type, int graph, int k, int complete, seams_cage_set **out)

Hexagonal and double-diamond cage membership.

Parameters

- **sys**: Frame handle.
- **cutoff**: Positive finite cutoff, Angstrom. The seeded graph uses cutoff + 1.5 as the candidate shell.
