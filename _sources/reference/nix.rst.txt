=========
Nix flake
=========


.. code:: bash

    nix build                  # ./result/bin/seams
    nix run . -- read input/traj/exampleTraj.lammpstrj
    nix develop
    nix flake update nixpkgs
    nix fmt

``nix build`` runs the Catch2 suite (Meson install check).

What the flake enables
----------------------

Eigen, BLAS/LAPACK, Catch2, Highway when nixpkgs has them. OpenMP when
the toolchain links it. Optional wrap-git backends (vesin,
readcon-core) and chemfiles stay off unless a nixpkgs package is
already in the closure.

Front-end flakes
----------------

`yodaStruct <https://github.com/d-SEAMS/yodaStruct>`_ and
`PydSEAMSlib <https://github.com/d-SEAMS/PydSEAMSlib>`_ have matching
flakes. They take seams-core as a locked source input and build it as
the Meson subproject.

Cachix
------

The `dseams <https://dseams.cachix.org/>`_ cache is optional:

.. code:: bash

    nix-env -iA cachix -f https://cachix.org/api/v1/install
    cachix use dseams
