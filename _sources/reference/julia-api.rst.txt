Julia
=====

Documenter-style docstrings from `Dseams.jl <https://github.com/d-SEAMS/Dseams.jl>`_ and the ``Seams`` package in that repository. ``Dseams`` is the language front. ``Seams`` calls ``libseams`` with ``ccall``.

----------

Generated from the sources named below. A name on this page is a public call in that language.

Dseams.cages
~~~~~~~~~~~~

.. api-symbol: Dseams.cages

.. code-block:: julia

   cages(frame; cutoff=3.5, type=0, k=4, graph="seeded") Hexagonal and double-diamond membership

cages(frame; cutoff=3.5, type=0, k=4, graph="seeded") Hexagonal and double-diamond membership. \`cage\` is 0 water, 1 hexagonal only, 2 double-diamond only, 3 both. The four counts are disjoint and match \`seams cages\`. \`cutoff\` is angstrom. A frame with no atoms gives an empty \`cage\` and four zero counts.

Dseams.chill_plus
~~~~~~~~~~~~~~~~~

.. api-symbol: Dseams.chill_plus

.. code-block:: julia

   chill_plus(frame; cutoff = 3.5, type = 0, graph = "cutoff") CHILL+ labels

chill\_plus(frame; cutoff = 3.5, type = 0, graph = "cutoff") CHILL+ labels. \`graph = "cutoff"\` (the default) bonds every pair closer than \`cutoff\`. \`graph = "mutual"\` bonds the mutual four nearest neighbours; \`cutoff + 1.5\` only sizes the search cells and does not bound a bond, so an atom with no neighbour within \`cutoff\` can still be bonded. A frame with no atoms gives empty \`labels\` and \`names\` and nine zero counts.

jump\_tau90(first, second, dt=1.0; oxygen\_type=1, hydrogen\_type=2) Time for an H-H vector to rotate 90 degrees between two frames. Returns \`dt\` when any water rotates that far, and \`NaN\` otherwise: when none does, when a frame has no water, or when \`dt\` is not positive.

Dseams.module
~~~~~~~~~~~~~

.. api-symbol: Dseams.module

.. code-block:: julia

   module

Dseams Julia front for the d-SEAMS engine. Calls \`libseams\_lang\` with \`ccall\`. The library comes from \`libseams\_jll\`. A local build is used instead when the \`SEAMS\_LANG\_LIB\` environment variable or the \`libseams\_lang\` preference names it; see [\`Dseams.set\_library!\`](@ref). CxxWrap is not required. Ice Ih (\`data/ice1h.lammpstrj\`, every atom) is 128 hexagonal waters and 256 primitive six-rings. The C API names re-exported here call \`libseams\` (\`SEAMS\_LIB\`, else the loader path) and are System, sea

q4\_q6(frame; cutoff=3.5, type=0) Local and Lechner-Dellago q4 and q6 on the cutoff shell. \`cutoff\` is angstrom. An atom with an empty shell has 0 for all four values, and a frame with no atoms gives empty vectors.

Dseams.read_frame
~~~~~~~~~~~~~~~~~

.. api-symbol: Dseams.read_frame

.. code-block:: julia

   read_frame(path; frame=1, type=0) Read one frame

read\_frame(path; frame=1, type=0) Read one frame. \`frame\` is 1-based. \`type = 0\` guesses oxygen. A positive type keeps that species. A negative type keeps every atom. A frame that holds no atoms, or none of the kept \`type\`, is a valid frame with \`nop(frame) == 0\`, and every analysis accepts it. A \`frame\` below 1, or past the last one in the file, throws [\`SeamsError\`](@ref); neither gives an empty frame.

Dseams.steinhardt
~~~~~~~~~~~~~~~~~

.. api-symbol: Dseams.steinhardt

.. code-block:: julia

   steinhardt(frame, order_l; cutoff=3.5, type=0, graph=nothing) Local Steinhardt parameter

steinhardt(frame, order\_l; cutoff=3.5, type=0, graph=nothing) Local Steinhardt parameter. \`order\_l\` is 3, 4, 6, 8, or 12, and any other degree throws [\`SeamsError\`](@ref). Omitting \`graph\` uses the cutoff shell. \`"mutual"\` is the four nearest neighbours, not bounded by \`cutoff\`. An atom with an empty shell has \`ql\` and \`qlbar\` equal to 0, and a frame with no atoms gives empty vectors.

.. code-block:: julia

symmetry(frame; shell\_rmsd=0.12) Per-atom shell label. 0 is ice Ih, 1 is ice Ic, 2 is stacking disorder, and -1 is anything else, which includes an atom with no neighbours. A frame with no atoms gives an empty vector.

Seams.module
~~~~~~~~~~~~

.. api-symbol: Seams.module

.. code-block:: julia

   Seams Julia front for the d-SEAMS C API (`include/seams.h`)

Seams Julia front for the d-SEAMS C API (\`include/seams.h\`). Set \`SEAMS\_LIB\` to \`libseams.so\` when it is not on the loader path. Handles are mutable structs with finalizers. A failing call throws [\`SeamsError\`](@ref). The message is \`seams\_handle\_error\`. \`System\`, \`Neighbours\`, \`Rings\`, and \`CageSet\` from the included C layer own their pointers. Result structs iterate in field order, so \`labels, counts = chill\_plus(sys)\` still unpacks. Ice Ih (seams-core \`input/traj/ice1h.lammpstrj\`, every atom)
