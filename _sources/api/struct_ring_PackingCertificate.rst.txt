Detailed Documentation
~~~~~~~~~~~~~~~~~~~~~~

Proof that the reported number of equatorial rings is maximum.

method 1: the mutual-conflict graph is the line graph of a bipartite graph, and a matching equals a König cover. method 2: each connected component was solved by branch-and-bound. The cover is a clique partition (an upper bound). When it equals the set, that partition is the certificate; otherwise the exhausted search is.
