Detailed Documentation
~~~~~~~~~~~~~~~~~~~~~~

This contains the bond classifier of enum class type :ref:`bond_type <doxid-namespacemol_sys_1a1c858200c3d088bf02839453d0f46328>`, and the bond correlation factor.

Contains specifically the members:

* Bond classifier or the type of the bond (staggered, eclipsed, out-of-range)

* Bond correlation factor
