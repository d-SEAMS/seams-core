Detailed Documentation
~~~~~~~~~~~~~~~~~~~~~~

This contains per-particle information.

Specifically

* Type ID

* Molecular ID

* Atom ID

* Coordinates

* Neighbourlist

* Bond correlation type of type :ref:`Result <doxid-structmol_sys_1_1_result>`

* Type of :ref:`atom_state_type <doxid-namespacemol_sys_1a13ffe3a39a0816627553f195e102abb5>` iceType

* In slice bool
