Detailed Documentation
~~~~~~~~~~~~~~~~~~~~~~

This contains per-particle information.

Specifically

* Type ID

* Molecular ID

* Atom ID

* Coordinates

* Neighbourlist

* Bond correlation type of type :ref:`Result <doxid-structmol_sys_1_1_result>`

* Type of :ref:`atom_state_type <doxid-group__mol_sys_1ga13ffe3a39a0816627553f195e102abb5>` iceType

* In slice bool
