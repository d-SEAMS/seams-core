Detailed Documentation
~~~~~~~~~~~~~~~~~~~~~~

Owned primitive-ring set.

Move-only. ``:ref:`begin <doxid-classseams_1_1_rings_1a3a503b36e7192dd58ce09db1f75c2664>``` and ``:ref:`end <doxid-classseams_1_1_rings_1a2776439d24c3f74b0e26587f4aed29e7>``` walk the rings and yield vertex indices.
