.. rubric:: Parameters:

.. list-table::
	:widths: 20 80

	*
		- max_lag

		- Maximum lag in frames, or 0 for all lags.

	*
		- origin_stride

		- Frame stride between origins.

	*
		- dt

		- Frame spacing.

	*
		- directed

		- True for directed ``(donor, acceptor)`` edges.
