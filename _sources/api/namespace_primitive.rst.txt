Detailed Documentation
~~~~~~~~~~~~~~~~~~~~~~

Functions for generating primitive rings.

This namespace contains struct definitions and functions that are used for generating primitive (shortest-path) rings (directed cyclic graphs).

The :ref:`Vertex <doxid-structprimitive_1_1_vertex>` object is a collection of elements for each point, required for graph traversal. The :ref:`Graph <doxid-structprimitive_1_1_graph>` object is an object for the whole frame, containing the information of all vertices, and a row-ordered vector of vector of the rings generated.

The `Franzblau shortest-path criterion <https://journals.aps.org/prb/pdf/10.1103/PhysRevB.44.4925>`__ has been used. The SP (shortest-path) criterion is midway between the least restrictive and most restrictive criteria in the hierarchy.

The following is the procedure for finding primitive rings:

#. All possible rings (including non-SP) rings are found, in the :ref:`primitive::countAllRingsFromIndex <doxid-namespaceprimitive_1ac81b1dd4b67e8200de61e52c498c1b2f>` function, using the `backtracking algorithm <https://www.math.upenn.edu/~wilf/website/CombinatorialAlgorithms.pdf>`__. This is a recursive algorithm.

#. The non-SP rings are then removed from the list of all rings, using the Franzblau shortest path criterion (:ref:`primitive::removeNonSPrings <doxid-namespaceprimitive_1a592086d3afae4fab5aa5ff6aa5c1d215>`), answered by a hop-bounded breadth-first sweep per vertex.

	std::vector<std::vector<int>> ringNetwork(const std::vector<std::vector<int>>& nList, int maxDepth)

Returns a vector of vectors containing the rings (of all sizes), by atom index, given the neighbour list also by index (preferably the hydrogen-bonded neighbour list). Each ring starts at its lowest-indexed member and runs toward the lesser of that member's ring neighbours, and the rings are sorted lexicographically.

	std::vector<std::vector<int>> ringNetworkBalls(const std::vector<std::vector<int>>& nList, int maxDepth)

The same ring set, built with a bounded ball at every vertex and a primitivity test of every pair. ringNetwork leaves that table out when the largest ring is at most 7, because a strict shortcut is then a walk of at most two edges. The timing harness compares the two.

.. index:: pair: function; lastRingSearchUsedBalls
.. _doxid-namespaceprimitive_1a78fa9b2181d5c4ee74a10363b84039e9:

.. ref-code-block:: cpp
	:class: doxyrest-title-code-block

	int lastRingSearchUsedBalls()

0 when the last ringNetwork call answered every primitivity query from the adjacency rows, 1 when it filled the sorted pair table, 2 when it filled the occupancy bitset of a radius-4 ball, 3 when a radius-2 pair table answers distance 4 by a meet in the middle. Rings of size at most 7 report 0. Rings of size 8 and 9 report 1. Rings of size 10 report 3. ringNetworkBalls always reports 1.
