	Msd(std::size_t natoms, std::size_t max_lag, std::size_t origin_stride, double dt, std::span<const double, 3> axis)

Allocate a streaming MSD accumulator.



.. rubric:: Parameters:

.. list-table::
	:widths: 20 80

	*
		- natoms

		- Particle count per frame.

	*
		- max_lag

		- Maximum lag in frames, or 0 for all lags.

	*
		- origin_stride

		- Frame stride between origins.

	*
		- dt

		- Frame spacing in physical time units.

	*
		- axis

		- Axial direction 3-vector.
