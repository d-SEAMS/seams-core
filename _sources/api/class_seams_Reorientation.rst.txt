Allocate a reorientation accumulator.



.. rubric:: Parameters:

.. list-table::
	:widths: 20 80

	*
		- n_vectors

		- Molecular vector count per frame.

	*
		- max_lag

		- Maximum lag in frames, or 0 for all lags.

	*
		- origin_stride

		- Frame stride between origins.

	*
		- dt

		- Frame spacing.
