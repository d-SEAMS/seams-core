Detailed Documentation
~~~~~~~~~~~~~~~~~~~~~~

Inclusive length window on each face edge, in the coordinate units of the frame.

The default covers the oxygen-oxygen contacts of the reference water cells when those units are angstroms. ``:ref:`enabled <doxid-structcage_1_1_edge_window_1a9464193ecc98f5488873959ab686df1a>` == false`` leaves the cage bound to the face census. A null coordinate pointer skips the test as well.
