Detailed Documentation
~~~~~~~~~~~~~~~~~~~~~~

Failure from the C API, or from a rejected argument.

``what()`` is the text from ``:ref:`seams_handle_error <doxid-group__capi__meta_1ga53c7d5d16b336c47ed94f5ea9a3f689f>```. ``:ref:`code() <doxid-classseams_1_1_error_1ab85bb0b64754ec9b459210f58350f930>``` is the status integer. The object does not own a handle.
