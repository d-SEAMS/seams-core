	std::vector<int> shellRingCensus(const std::vector<std::vector<int>>& rings, const std::vector<int>& shell, int maxRingSize)

Rings of the water network that pass through a first shell: the census by size of every ring with at least one vertex in ``shell``.

An ion is not a vertex of the network, so the rings it would have closed are gone and the rings its shell still carries measure how far the network survives around it (the hydration-shell ring census of a brine or an ionic solution). ``census[s]`` counts rings of size s up to ``maxRingSize``.

	std::vector<std::vector<int>> brokenRings(const std::vector<std::vector<int>>& nList, const std::vector<int>& shell, int maxRingSize)

Broken rings: the primitive rings, of at most ``maxRingSize`` members, of the water graph ``nList`` (by index, leading self entry, ions not bonded) plus one virtual ion vertex bonded to every water of ``shell``, that contain the ion.

These are the rings the water-only network lost. Each ring is in ring order and writes the virtual ion as ``static_cast<int>(nList.size())``.

.. index:: pair: function; pointInFacesTrace
.. _doxid-namespacesite_1aeeb8b9fec48dcc2b70f40cafe705a0c2:

.. ref-code-block:: cpp
	:class: doxyrest-title-code-block

	:ref:`InsideTrace<doxid-structsite_1_1_inside_trace>` pointInFacesTrace(const :ref:`molSys::PointCloud<doxid-structmol_sys_1_1_point_cloud>`<:ref:`molSys::Point<doxid-structmol_sys_1_1_point>`<double>, double>& yCloud, const std::vector<std::vector<int>>& rings, const std::vector<int>& faces, const std::array<double, 3>& guest, const std::array<double, 3>* center = nullptr)

The inside predicate for one cage.

The face vertices and the guest are unwrapped about c_F (``center``, or the periodic centroid of the distinct face vertices when null) and each face is fan-triangulated from its own centroid. The guest is inside when it lies on a triangle within ``:ref:`kInsideRelTol <doxid-namespacesite_1a17c7ad054eafa92f5e5238e14109b97a>```; otherwise a ray is cast along the first direction of ``:ref:`insideRayDirections() <doxid-namespacesite_1a9231f841816296c279bcf08186f332de>``` that passes no triangle edge or vertex within that tolerance, and the guest is inside when the ray meets an odd number of triangles. When every direction grazes, the one with the widest clearance decides.

.. index:: pair: function; guestOccupancyInside
.. _doxid-namespacesite_1a84113178c851924869bd3fee27af749b:

.. ref-code-block:: cpp

	:ref:`GuestOccupancy<doxid-structsite_1_1_guest_occupancy>` guestOccupancyInside(const :ref:`molSys::PointCloud<doxid-structmol_sys_1_1_point_cloud>`<:ref:`molSys::Point<doxid-structmol_sys_1_1_point>`<double>, double>& yCloud, const std::vector<std::vector<int>>& rings, const std::vector<std::vector<int>>& cageFaces, const std::vector<int>& guestIndices)

Occupancy by the inside predicate (``:ref:`pointInFaces <doxid-namespacesite_1a5e215d2d1aaa78e5e54c511d3617ea1d>```) on every cage.

Among cages that contain the guest the nearest centroid wins. ``rings`` is the ring list the cage faces index; ``cageFaces[c]`` is the face indices of cage c.
