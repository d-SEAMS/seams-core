Detailed Documentation
~~~~~~~~~~~~~~~~~~~~~~

Three-dimensional partial RDF g_IJ(r).

Pair distances use :ref:`gen::periodicDist <doxid-namespacegen_1a4038dadde6016e7a738c2cb015344ee3>`, so a sheared dump cell uses the same minimum image as the neighbour lists. The ideal-gas denominator uses the triclinic volume from :ref:`nneigh::dumpVolume <doxid-namespacenneigh_1ad17e972366865905372aa796e946a351>` (det H), not the product of bound spans.
