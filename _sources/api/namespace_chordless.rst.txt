	std::size_t cycles(const std::vector<int>& offsets, const std::vector<int>& cols, int size, std::vector<int>* rings, int* per_atom)

Chordless cycles of one size on a CSR graph.

A cycle is chordless when no edge joins two of its vertices that are not neighbours on the cycle. Each cycle is listed once, starting at its lowest vertex, in the direction whose second vertex is the smaller of that vertex's two cycle neighbours. The list is sorted lexicographically, so it does not depend on the thread count.



.. rubric:: Parameters:

.. list-table::
	:widths: 20 80

	*
		- offsets

		- n + 1 row offsets.

	*
		- cols

		- Column indices. Self entries must not appear.

	*
		- size

		- Cycle length, from 3 through kMaxSize.

	*
		- rings

		- When not null, receives count \* size vertex indices.

	*
		- per_atom

		- When not null, n counts of cycles through each vertex.



.. rubric:: Returns:

The number of cycles.
