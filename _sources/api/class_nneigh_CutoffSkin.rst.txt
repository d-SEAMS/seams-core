Detailed Documentation
~~~~~~~~~~~~~~~~~~~~~~

In-situ cutoff list.

Candidates are built at ``cutoff + skin`` and reused while every atom and the box have moved by at most ``skin/2``. The filtered list matches a fresh build at ``cutoff``.
