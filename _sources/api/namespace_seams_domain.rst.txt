	std::vector<std::vector<int>> rings(const :ref:`Cloud<doxid-namespaceseams_1_1domain_1ab1bfe8a7863d4a64c57f3ea273eacfc3>`& cloud, double cutoff, int maxDepth, int rank, int nRanks)

Primitive rings of the cutoff graph up to *maxDepth* members whose lowest-indexed member rank *rank* owns, by frame index, as :ref:`primitive::ringNetwork <doxid-group__primitive_1ga69f1b870183f33e58426c88ee93f0635>` lists them for the graph with ascending rows. Each rank needs only its share, and the ranks' rings partition the frame's.
