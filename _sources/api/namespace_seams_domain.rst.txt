	int ringHops(int maxDepth)

Cutoffs of coordinates a rank needs when it builds every neighbour row itself. A primitive ring of *maxDepth* members stays inside this many hops, and one hop is at most one cutoff.

.. index:: pair: function; ringRowHops
.. _doxid-namespaceseams_1_1domain_1ae27bcdb378d3e3ff8d64c523885ba8fc:

.. ref-code-block:: cpp
	:class: doxyrest-title-code-block

	int ringRowHops(int maxDepth)

Cutoffs of neighbour rows the ring search reads past the owned block. The coordinate halo on the distributed path is one cutoff; rows out to this reach are computed by their owners and exchanged. Edges that leave the reach are dropped, which is the graph a coordinate halo of this many cutoffs would have built.

	std::vector<std::vector<int>> rings(const :ref:`Cloud<doxid-namespaceseams_1_1domain_1ab1bfe8a7863d4a64c57f3ea273eacfc3>`& cloud, double cutoff, int maxDepth, int rank, int nRanks)

Primitive rings of the cutoff graph up to *maxDepth* members whose lowest-indexed member rank *rank* owns, by frame index, as :ref:`primitive::ringNetwork <doxid-group__primitive_1ga69f1b870183f33e58426c88ee93f0635>` lists them for the graph with ascending rows. 	std::vector<std::vector<int>> ringsFromRows(const std::vector<int>& frame, const std::vector<std::vector<int>>& neigh, const std::vector<int>& sources, int maxDepth)

Primitive rings from neighbour rows already in hand. *frame* [i] is the frame index of a vertex whose neighbours are *neigh* [i], also frame indices. A neighbour that is not one of *frame* is dropped. *sources* lists the frames that may enumerate a ring. Members in the result are frame indices.
