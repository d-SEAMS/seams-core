Detailed Documentation
~~~~~~~~~~~~~~~~~~~~~~

Bare-bones structs used throughout the architecture.

@detials This namespace defines :ref:`Point <doxid-structmol_sys_1_1_point>` and :ref:`PointCloud <doxid-structmol_sys_1_1_point_cloud>` structs, alongwith other basic functions and enums.

:ref:`PointCloud <doxid-structmol_sys_1_1_point_cloud>` is a struct that contains the information of a collection of :ref:`Point <doxid-structmol_sys_1_1_point>` structs, at every frame. :ref:`Point <doxid-structmol_sys_1_1_point>` contains the coordinates and types of each point, along with information about whether the particular particle is within a slice or not.
