Detailed Documentation
~~~~~~~~~~~~~~~~~~~~~~

One directed hydrogen bond.

Indices are frame indices. Heavies from set_hydrogen_frame occupy ``[0, n_heavy)`` and hydrogens follow. ``:ref:`angle <doxid-structseams_1_1_directed_bond_1ab689f971ef44723d48ccf6415f721c78>``` is acceptor-first degrees: 0 is a linear donor-hydrogen-acceptor geometry.
