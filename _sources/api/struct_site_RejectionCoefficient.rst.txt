Detailed Documentation
~~~~~~~~~~~~~~~~~~~~~~

k = c_ice / c_liquid, both molalities of formula units.

``:ref:`defined <doxid-structsite_1_1_rejection_coefficient_1a32d741a29d36faf7a950d0551458dd95>``` is false when the liquid bulk contains no salt and the ice bulk does, because the ratio is then unbounded.
