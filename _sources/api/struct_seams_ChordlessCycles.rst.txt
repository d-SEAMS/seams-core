Detailed Documentation
~~~~~~~~~~~~~~~~~~~~~~

Chordless cycles of one length.

``:ref:`atoms <doxid-structseams_1_1_chordless_cycles_1ad77d911d26cc14072ee815b90a87bfbd>``` holds :ref:`count() <doxid-structseams_1_1_chordless_cycles_1a03ffa11ffd11a5a39645c7627541b9de>` rows of ``:ref:`size <doxid-structseams_1_1_chordless_cycles_1a5f95f7eec618c43954613bbe0a384efb>``` atom indices, in the order seams_rings_chordless writes them. ``:ref:`per_atom <doxid-structseams_1_1_chordless_cycles_1a3e3866f354fc62751edb2b80574823b7>``` is the number of cycles through each atom.
