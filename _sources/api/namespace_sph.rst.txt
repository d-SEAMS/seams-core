Detailed Documentation
~~~~~~~~~~~~~~~~~~~~~~

Functions used for spherical harmonics.

The recommended function for calculating the spherical-harmonics based complex vector is :ref:`sph::spheriHarmo <doxid-namespacesph_1aa9220b76da7400c9d934fa08ceeeba7a>`. This function uses the `Boost <https://www.boost.org/>`__ libraries.
