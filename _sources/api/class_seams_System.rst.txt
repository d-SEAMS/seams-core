Detailed Documentation
~~~~~~~~~~~~~~~~~~~~~~

One frame: coordinates, a cell, and the analyses that read them.

Move-only. The destructor frees the C handle. Methods that read the frame require exclusive use of this object. The :ref:`Steinhardt <doxid-structseams_1_1_steinhardt>` scratch inside the library is process-global, so two frames must not run ``:ref:`steinhardt <doxid-namespaceseams_1_1steinhardt>```, ``:ref:`ql <doxid-classseams_1_1_system_1a6327a361caa00807236bb9a6b06baf59>```, ``:ref:`q4q6 <doxid-classseams_1_1_system_1a70a06e349cc0b7d0e40548688bdd6c78>```, or ``:ref:`q6bar <doxid-classseams_1_1_system_1a2a2161e5b3ef753e7a30770b5ae8f9ad>``` at the same time. ``:ref:`set_num_threads <doxid-group__seams__cpp_1gade81b9f566b717d94390a5499824893f>``` is also process-global.
