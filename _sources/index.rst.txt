Overview
--------

d-SEAMS reads a molecular-dynamics trajectory and names the ice in it.
The name is Deferred Structural Elucidation Analysis for Molecular
Simulations. This release of the repository is the C++ engine
``libyodaLib``, the C API ``libseams`` (``include/seams.h``), the header-only
C++ API ``include/seams.hpp`` (it links ``libseams``), the C ABI
``libseams_lang`` (``bindings/cxx/seams_lang.h``, used by the Python, R, and
Julia fronts), the ``seams`` command, and the LAMMPS, GROMACS, OpenMM,
PLUMED, and in-situ drivers. ``gmx-seams`` reads the trajectory ``gmx mdrun`` wrote.
The standalone PLUMED action (``dseams-plumed`` v0.4.1) is indexed in
`PLUMED-NEST egg 26.018 <https://www.plumed-nest.org/eggs/26/018/>`_.
``seams --version`` prints the project version.


Large tutorial and benchmark trajectories live in the public
``d-SEAMS/seams-core-inputs`` Hugging Face dataset. Run
``python3 input/fetch.py`` from the checkout to download all three files
and verify their SHA-256 digests. See
`Data formats and trajectory inputs <reference/data-formats.rst>`_.

See the :doc:`engines/plumed` page for the plugin.

CHILL+ labels an oxygen from its four-neighbour star: cubic, hexagonal,
interfacial, clathrate, interClathrate, or water. Cage membership is a
separate score. A molecule in a hexagonal cage (HC) is ice Ih. A molecule
in a double-diamond cage (DDC) is ice Ic. A molecule in neither is water.
Primitive rings and Steinhardt :math:`q_l` are computed in the same engine.
`CHILL+ versus cages <explanation/chill-plus-vs-cages.rst>`_ records
where the two scores disagree.

A source build from this tree, when the compilers are already on ``PATH``,
is ``meson setup build && meson compile -C build``.
pixi is ``pixi run setup && pixi run build``.
`Install <getting-started/install.rst>`_ has each method.

The ice Ih frame shipped in this tree is ``input/traj/ice1h.lammpstrj``,
128 molecules of LAMMPS type 1.

.. code:: bash

    seams read input/traj/ice1h.lammpstrj
    seams chill-plus input/traj/ice1h.lammpstrj --cutoff 3.5

``seams read`` prints ``nop 128 frame 1 box 15.6457 14.7071 18.073``.
``seams chill-plus`` prints ``nop 128 hexagonal 128``.
`The quick start <getting-started/quickstart.rst>`_ classifies an eight-atom cubic
cell from C and from Python.
`From a trajectory to the ice front <user/howto/from-trajectory.rst>`_
adds the ring census on this frame and the ice front on
``input/traj/interface_f0.lammpstrj``.

Each other language is its own repository.
`Use a language binding <user/howto/bindings.rst>`_ names the package
and the library each one links.

- Python: ``pydseamslib`` (``import dseams``, ``import pydseams``),
  with ``pip install pydseamslib`` from
  `PydSEAMSlib <https://github.com/d-SEAMS/PydSEAMSlib>`_

- Lua and Fennel: ``require("dseams")``, clone
  `yodaStruct <https://github.com/d-SEAMS/yodaStruct>`_ and run ``luarocks make`` in the checkout

- R: ``remotes::install_github("d-SEAMS/dseams-r")`` from `dseams-r <https://github.com/d-SEAMS/dseams-r>`_

- Julia: ``Pkg.add(url="https://github.com/d-SEAMS/Dseams.jl")`` from
  `Dseams.jl <https://github.com/d-SEAMS/Dseams.jl>`_

- Rust: ``cargo add dseams`` from `dseams-rs <https://github.com/d-SEAMS/dseams-rs>`_

- Fortran: fpm Git dependency ``dseams`` from `dseams-fortran <https://github.com/d-SEAMS/dseams-fortran>`_

`The 2.14.3 notes <reference/release-2.14.rst>`_ are the changes
since 2.13.0.
`Migrate from 1.x <user/howto/migrate-1x.rst>`_ maps ``yodaStruct -c``
onto ``seams``.

Suite stack
-----------

.. mermaid::

   flowchart TD
     DUMP["LAMMPS dump and XYZ"] --> LIB[libyodaLib]
     NB["linkcell"] --> LIB
     LIB --> CLI[seams]
     LIB --> API[libseams]
     LIB --> ABI["libseams_lang<br/>Python, R, Julia"]

``libyodaLib`` reads a LAMMPS dump or an XYZ file. chemfiles
(``.pdb``, ``.gro``, ``.dcd``) and the ``.con`` reader are compiled in when
those libraries are found. The cutoff and k-nearest neighbour lists are
linkcell's. ``seams --features`` prints
which backends this binary has. The ``seams`` command, ``libseams``, and
``libseams_lang`` each link ``libyodaLib``. ``include/seams.hpp`` links
``libseams``. Python and Julia link both libraries. R links
``libseams_lang``. Lua, Rust, and Fortran link ``libseams``.
